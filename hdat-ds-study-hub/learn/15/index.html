먼저 떠올릴 장면

눈금 몇 개가 흔들리는 측정 자료에 곡선을 맞춘다고 하자. 아주 복잡한 곡선은 모든 점을 지나가지만 새 측정값 사이에서는 요동칠 수 있다. 반대로 직선 하나는 너무 단순해서 실제 곡률도 놓칠 수 있다. 모델을 크게 만드는 것과 새로운 자료에서 잘 작동하게 만드는 것은 같은 목표가 아니다. 규제는 학습 자료의 우연한 흔들림까지 지나치게 따라가지 않도록 학습에 제약을 주는 방법이다.

시험 준비에서도 같은 모의고사 한 세트만 수백 번 풀면 그 세트 점수는 높아진다. 모델 종류·학습률·규제 강도를 validation 하나에서 계속 선택하는 일도 비슷하다. 실험 설계는 더 많은 후보를 돌리는 기술만이 아니라, 어느 변경이 실제로 도움이 되었는지 비교 가능한 증거를 남기는 기술이다. 작은 예산에서는 좋은 baseline과 통제된 몇 번의 비교가 특히 중요하다.

낯선 말부터 풀기

parameter는 데이터에서 학습하는 가중치 w와 편향 b다. hyperparameter는 학습률, 깊이, 은닉 유닛 수, L1/L2 강도, dropout 비율처럼 학습 절차 바깥에서 선택하는 값이다. 규제 목적함수를 J(w)=L_data(w)+λR(w)로 쓰자. L_data는 예측 오차, R은 복잡성에 대한 벌점, λ는 그 벌점의 중요도다. λ가 클수록 자료에 맞추는 일보다 제약을 더 강하게 고려한다.

L1 벌점은 Σ|w_j|, L2 벌점은 Σw_j²다. L1은 일부 계수를 정확히 0으로 만드는 희소해를 유도할 수 있고 L2는 큰 계수에 더 큰 비용을 매긴다. 다만 ‘L1을 쓰면 무조건 정확히 몇 개 특성이 제거된다’고 말할 수는 없다. 학습법과 데이터, λ에 따라 결과가 달라진다. optimizer의 weight decay는 갱신 단계에서 값을 축소하는 방식이며, 특히 Adam 계열에서는 L2 벌점을 loss에 넣는 것과 분리된 weight decay가 일반적으로 같지 않다.

그림을 읽는 순서

먼저 축·색·연결 방향을 읽고, 각 그림 아래의 설명으로 확인하세요. 이어지는 손계산은 같은 개념을 다른 작은 숫자로 연습할 수도 있습니다.

숫자로 끝까지 따라가기

아래 가중치와 학습곡선 값은 그림의 실측값이 아니라 수식과 체크포인트 선택을 확인하기 위한 독립 예다.

가중치가 [2,−1], 평균 데이터 오차가 0.4, λ=0.1이라고 하자. L1의 합은 |2|+|−1|=3이므로 목적함수는 0.4+0.1×3=0.7이다. L2의 합은 2²+(−1)²=5이므로 0.4+0.1×5=0.9다. L2를 λ/2로 정의하는 교재도 있으므로 계수는 문제에 나온 정의를 따른다.

가중치 한 개 w=2, 데이터 오차 기울기 g=0.5, 학습률 η=0.1, λ=0.1을 보자. 규제 없으면 w_new=2−0.1×0.5=1.95다. λw²를 더하면 규제 기울기는 2λw=0.4, 전체 기울기는 0.9, 새 가중치는 1.91이다. λ|w|의 w>0 영역에서는 규제 기울기가 λ=0.1이므로 새 값은 1.94다. L2가 큰 값에 비례하는 힘을 주는 이유가 숫자로 드러난다.

validation loss가 epoch별 [0.8,0.6,0.55,0.58,0.62]라면 가장 좋은 것은 epoch 3이다. patience=2, 엄격한 개선을 기준으로 하면 두 번 연속 개선이 없는 epoch 5에서 멈출 수 있지만 돌아가 사용할 가중치는 epoch 3의 것이다. ‘멈춘 시점’과 ‘최선의 저장 시점’을 분리해야 한다.

PYTHON · 작은 예제로 직접 확인
import numpy as np

w = np.array([2., -1.])
data_loss, lam = .4, .1
print("L1 objective:", data_loss + lam * np.abs(w).sum())
print("L2 objective:", data_loss + lam * (w ** 2).sum())
valid = np.array([.8, .6, .55, .58, .62])
best_epoch = int(valid.argmin()) + 1
assert best_epoch == 3

# 실제 성능이 아니라 탐색 후보의 규모를 비교하는 예다.
rng = np.random.default_rng(42)
lr_candidates = 10 ** rng.uniform(-4, -2, size=4)
print("best epoch:", best_epoch)
print("random log-scale LR:", lr_candidates)

시험 문제로 연결하기

grid search에서 학습률 4개, 깊이 3개, dropout 3개를 모두 조합하면 36회다. 여기에 5-fold를 쓰면 180번 학습한다. 한 학습이 30초만 걸려도 모델 학습만 90분이다. 전처리, 평가, 저장, 실패 복구 시간은 아직 포함하지 않았다. random search는 미리 정한 횟수만 뽑을 수 있고, Bayesian search는 이전 평가를 이용해 다음 후보를 고른다. 어느 방식도 제한된 validation에서 선택한다는 근본 문제를 없애지는 않는다. scikit-learn 하이퍼파라미터 탐색 안내는 탐색 방법과 평가의 연결을 정리한다.

공정한 비교에는 같은 데이터 분할, 전처리, 지표, seed 정책, 예산을 사용한다. baseline에서 dropout만 추가한 run과 학습률까지 함께 바꾼 run을 비교하면 무엇이 원인인지 분리하기 어렵다. 한 번에 한 변경을 하고 run 이름·설정·점수·실행 시간·실패 원인을 남기자. epoch가 같아도 모델마다 비용이 다르므로 시간 제한이 중요한 상황에서는 같은 wall-clock 예산 비교도 유용하다. 최종 후보를 정한 후 전체 train으로 재학습하는 단계는 validation으로 후보를 고르는 단계와 별도다.

자주 헷갈리는 지점

규제를 늘리면 언제나 validation이 좋아지는 것은 아니다. 이미 train도 잘 못 맞추는 모델에 dropout을 크게 늘리면 underfit이 더 심해질 수 있다. underfit처럼 보여도 입력 정규화, 잘못된 label, 너무 작거나 큰 학습률이 원인일 수 있으므로 용량부터 늘리지 않는다. 초기 몇 epoch가 우연히 좋았다고 너무 짧은 patience로 멈추는 것도 문제다. early stopping은 test를 보고 실행하지 않고 validation 지표의 방향을 확인한다. loss는 작을수록, F1이나 AUC는 클수록 좋은 경우가 일반적이다.

필기 이론: 정의에서 풀이까지

공식의 기호와 성립 조건을 풀고, 문제와 다른 숫자의 예제로 계산 과정을 배웁니다. 각 절 끝에는 이 개념을 적용할 문제로 돌아가는 링크가 있습니다.

1. 훈련 오차·일반화·bias와 variance

훈련 오차가 낮다는 것은 이미 본 자료를 잘 맞추었다는 뜻이다. 일반화는 같은 목표 환경의 새로운 자료에서도 잘 예측하는 능력이다. 모델이 너무 제한되어 진짜 곡률을 표현하지 못하면 train과 valid 모두 나쁠 수 있다. 반대로 데이터의 측정 잡음까지 복잡한 경계로 따라가면 train은 좋고 valid는 나쁠 수 있다. 각각 underfitting과 overfitting의 대표 모습이다. 다만 잘못된 target, 잘못된 split, 너무 큰 학습률도 비슷한 곡선을 만들므로 곡선만으로 원인을 확정하지 않는다.

제곱오차의 bias-variance 관점은 같은 모집단에서 훈련 자료를 여러 번 다시 뽑는 상상에서 시작한다. 특정 x에 대해 여러 모델의 평균 예측이 참 평균 함수 f(x)에서 벗어난 정도가 bias, 다시 뽑을 때 예측이 흔들리는 정도가 variance다. 독립 잡음과 제곱오차 등의 조건에서 기대 예측 오차는 bias²+variance+줄일 수 없는 잡음 분산으로 나뉜다. 이 variance는 validation fold 점수의 표준편차와 관련은 있을 수 있어도 동일한 정의는 아니다. 규제는 복잡한 적합을 제한해 variance를 줄이는 대신 bias를 늘릴 수 있다. 강할수록 무조건 좋지 않은 이유다.

2. L1·L2의 벌점과 미분을 연결한다

목적함수를 J(w)=L_data(w)+λR(w)라고 쓰자. w는 학습 가중치, L_data는 자료 예측 손실, R은 가중치에 대한 벌점, λ≥0은 중요도다. L1은 Σ_j|w_j|, L2는 Σ_jw_j²다. 어떤 교재는 L2 앞에 1/2를 붙이므로 수치 계산에서는 주어진 식을 우선한다. 모델의 bias 항을 규제할지와 입력 scaling도 결과를 바꾼다. 동일 예측을 만드는 가중치라도 특성 단위를 바꾸면 크기가 달라지므로 규제와 전처리는 연결되어 있다.

손계산 예 A: w=[1,−3], L_data=0.2, λ=0.05이면 L1 벌점은 0.05×4=0.2, 전체 목적은 0.4다. L2 벌점은 0.05×10=0.5, 전체 목적은 0.7이다. 벌점이 더 크다는 사실만으로 그 학습법의 최종 정확도가 나쁘다는 결론을 내릴 수는 없다. 최적 가중치 자체가 달라지기 때문이다.

w≠0에서 λ|w|의 미분은 λ sign(w)다. λw²의 미분은 2λw라서 큰 가중치일수록 더 큰 축소 힘을 받는다. w=0에서 L1은 보통 미분이 없고 부분미분이라는 허용 기울기 구간을 사용한다. 원점의 뾰족함 때문에 특정 최적화 조건에서 정확한 0의 해가 자연스럽게 나온다. 그렇다고 단순 SGD 몇 번만으로 모든 작은 값이 정확히 0이 된다고 보장되지는 않는다.

3. weight decay·Dropout·중단 시점은 다른 제약이다

순수 SGD에 λw²/2를 loss로 더하면 w_new=w−η(g+λw)=(1−ηλ)w−ηg다. g는 자료 손실의 gradient, η는 학습률이다. 이 식에서 가중치 자체를 일정 비율 줄이는 weight decay와 관계를 볼 수 있다. 적응적으로 좌표별 보폭을 나누는 Adam에 규제 gradient를 함께 넣으면 그 항도 같은 변환을 받는다. AdamW는 축소를 분리하므로 일반적으로 동일하지 않다. AdamW 원 논문은 이 구분을 다룬다.

Dropout은 훈련 중 일부 activation을 지워 특정 연결 조합에만 의존하는 것을 줄인다. 학습률이 너무 작거나 모델 용량이 이미 부족한 경우 큰 dropout은 학습을 더 어렵게 만들 수 있다. 데이터 증강은 정답을 보존하는 변환으로 관측 다양성을 늘리는 방법이다. 좌우가 정답인 과제에서 좌우 반전은 무조건 정답 보존이 아니므로 변환 목록을 외워 적용하지 않는다. BatchNorm의 주 역할은 정규화를 통한 학습 과정 조정이며 dropout과 같은 목적으로만 설명하지 않는다.

손계산 예 B: validation loss가 [0.9,0.7,0.68,0.70,0.69,0.72], patience=2이며 strict improvement를 쓴다고 하자. epoch 3이 최선이다. 4와 5에서 연속으로 개선이 없으므로 epoch 5에서 멈춘다. 사용할 가중치는 epoch 5가 아니라 저장한 epoch 3이다. F1처럼 클수록 좋은 metric이면 최대값을 선택해야 한다. patience와 min_delta의 세부 정의를 적어야 서로 다른 구현의 중단 시점을 비교할 수 있다.

4. parameter와 hyperparameter, 그리고 탐색 비용

parameter는 backward와 optimizer로 배우는 w와 b다. hyperparameter는 학습률, 층 수, 은닉 크기, batch size, 규제 강도 등 학습 절차를 정하는 설정이다. 후보를 validation으로 골랐다는 의미에서는 hyperparameter도 데이터를 통해 선택되지만, 한 모델의 일반적인 gradient update로 직접 배우는 값과 구분한다. 학습한 모델의 가중치가 수백만 개여도 탐색할 설정은 몇 개일 수 있다.

learning rate 0.0001에서 0.001로 바뀌는 것은 열 배, 0.001에서 0.01도 열 배다. 이런 값은 여러 자릿수에 걸쳐 비율 변화가 중요하므로 로그 간격으로 탐색한다. 반면 정수 층 수를 반드시 로그 간격으로 고를 이유는 없다. λ=0은 log(0)이 정의되지 않으므로 규제 없음 후보로 따로 넣는다.

grid search에서 학습률 5개·깊이 2개·규제 4개를 모두 쓰면 후보 40개다. 3-fold이면 120회 fit이다. random search는 고정된 예산만큼 서로 다른 조합을 뽑는다. 만약 성능이 사실상 학습률 하나에 주로 좌우된다면 5×5 격자는 25회 동안 학습률 다섯 값만 경험하지만, 연속분포에서 25회 random search는 대체로 서로 다른 학습률 25개를 경험한다. 이것이 일부 축만 중요하고 예산이 작은 경우의 이점이다. 어느 문제에서도 random이 항상 grid를 이기는 정리는 아니다.

5. 많이 비교할수록 best score가 과장되는 이유

각 후보의 validation 점수에는 실제 실력과 우연한 표본 효과가 섞인다. 실제 실력이 같은 후보가 많아도 그중 최고 점수는 운이 좋았던 후보일 가능성이 높다. 후보 수가 늘수록 좋은 우연을 고를 기회도 늘어난다. 그래서 같은 validation에서 수많은 설정을 골라 얻은 최고점은 선택 과정과 독립인 최종 점수로 보지 않는다. test를 마지막까지 남기거나 바깥쪽 CV에서 선택 절차 전체를 평가하는 이유다.

ablation은 효과를 분리하려는 비교다. A와 B에서 같은 split·입력 자료·전처리·metric·seed 정책·학습 예산을 쓰고 한 요소만 바꾸면 원인을 해석하기 쉽다. 같은 epoch라도 큰 모델이 훨씬 오래 걸리면 시간 제한 과제에서 공정한 예산인지 생각해야 한다. seed 하나를 같게 했다고 서로 다른 구조의 모든 무작위성이 완전히 동일해지는 것은 아니므로 여유가 있으면 여러 seed의 paired 비교도 본다. 실험 기록에는 설정뿐 아니라 실행 시간과 실패 이유도 남긴다.

공식 근거: scikit-learn 선형모델의 Ridge·Lasso, 하이퍼파라미터 탐색, nested와 non-nested CV 비교. 규제 식, 탐색 예산, 독립 평가를 한 흐름으로 읽는다.

15.2 규제의 목적

규제는 모델이 train의 우연한 패턴을 과도하게 맞추는 것을 줄인다.

  • L1: loss에 λΣ|w|, sparsity 유도
  • L2: loss에 λΣw², 큰 weight 억제
  • Weight decay: optimizer update에서 parameter 축소
  • Dropout: train 중 activation 일부를 무작위 0
  • Early stopping: validation 악화 전 best checkpoint 선택
  • Data augmentation: label-preserving 변형으로 유효 데이터 다양화
  • Batch normalization은 주 목적이 규제는 아니지만 batch noise가 약한 규제 효과를 낼 수 있음

15.3 underfit과 overfit 처방

상태 train valid 처방 방향
underfit 나쁨 나쁨 feature/capacity/epoch↑, 규제↓
overfit 좋음 나쁨 데이터/규제↑, capacity/epoch↓, split 확인
둘 다 좋음 좋음 좋음 제출 확보, 작은 개선만
valid가 비정상적으로 훨씬 좋음 더 나쁨 더 좋음 augmentation/dropout 차이 또는 누수·분포 확인

15.4 hyperparameter와 parameter

Parameter는 학습으로 얻는 weight/bias. Hyperparameter는 learning rate, depth, hidden size, batch size, regularization strength처럼 학습 전/외부에서 정한다.

15.5 탐색 방법

  • Grid search: 후보 조합 전부. 차원이 늘면 폭발.
  • Random search: 정해진 횟수만 무작위. 중요한 일부 차원 탐색에 효율적.
  • Bayesian optimization: 과거 결과로 다음 후보 선택. 설정 overhead와 라이브러리 의존.
  • Manual coarse-to-fine: 실기에서 가장 현실적. LR/모델 크기 등 핵심 한두 축만.

로그 scale parameter(LR, weight decay)는 [1e-5,1e-4,1e-3]처럼 log 간격으로 본다.

15.6 공정한 ablation

한 번에 한 요소만 바꾸고 같은 split, seed, epoch/time budget, metric을 사용한다.
