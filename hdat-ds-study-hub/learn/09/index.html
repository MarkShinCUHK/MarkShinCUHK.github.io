먼저 떠올릴 장면

자동차의 주행거리와 사용한 연료량을 각각 아는 것과 “연료 1리터당 주행거리”를 아는 것은 어떻게 다를까? 원래 값이 있으면 비율을 계산할 수 있지만 어떤 모델은 그 관계를 쉽게 배우지 못한다. 사람이 비율을 새 열로 만들어 주면 예측에 유용한 관계를 입력에 미리 반영할 수 있다. 반대로 거의 같은 값을 가진 센서 열이 열 개 있다면 중복을 일부 줄여 학습 부담을 낮출 수 있다. 이때 새 열 만들기, 기존 열 고르기, 여러 열을 조합해 새 좌표 만들기는 서로 다른 작업이다.

특성이 많으면 무조건 좋다는 생각도 경계한다. 불필요한 열은 메모리와 계산량을 늘리고 작은 데이터에서 우연한 관계를 학습하게 할 수 있다. 그러나 분산이 작거나 단독 상관이 낮다고 무조건 쓸모없는 것도 아니다. 이번 장의 PCA 예제에서는 전체 퍼짐의 80%를 남겼는데 정작 클래스 구분이 사라지는 상황을 직접 계산한다.

낯선 말부터 풀기

특성 공학(feature engineering)은 문제의 구조를 활용해 특성을 만드는 일이다. 두 센서의 차이, 거리/연료 비율, 날짜의 시간대, 과거 평균 등이 해당한다. 특성 선택(selection)은 원래 특성 중 일부를 고르므로 남은 열의 의미가 유지된다. 특성 추출(extraction)은 여러 특성을 새로운 값으로 변환하는 일이다. PCA처럼 입력 열의 선형 결합으로 새 좌표를 만들 수 있다. 차원축소는 데이터를 나타내는 숫자 수를 줄이는 것이며, 특성 선택과 추출 모두 그 방법이 될 수 있다.

특성 선택은 세 계열로 나눌 수 있다. 필터 방식은 분산·상관관계·통계적 연관처럼 모델을 반복 학습하지 않아도 계산할 수 있는 기준으로 고른다. 카이제곱 기반의 일부 구현은 음수가 아닌 입력을 요구하는 등 각 기준의 가정을 확인해야 한다. 래퍼 방식은 열 조합을 바꾸며 특정 모델의 성능을 평가한다. RFE는 모델을 학습하고 중요도가 낮은 열을 제거하기를 반복하는 재귀적 특성 제거다. 내장형 방식은 L1 계수나 트리 중요도처럼 모델 학습 과정에서 얻은 값으로 특성을 고른다. 세 계열은 속도, 계산 비용, 상호작용을 찾는 능력, 특정 모델에 의존하는 정도가 다르다.

PCA의 주성분은 중심화한 입력이 많이 퍼져 있는 방향을 골라 만든 서로 직교하는 축이다. 고유값 λ는 그 방향의 분산이고, 설명분산비는 λ를 모든 고유값의 합으로 나눈 비율이다. 여기서 분산은 정답과 무관한 입력 X의 퍼진 정도다. LDA는 클래스 평균 사이는 멀어지고 같은 클래스 안에서는 상대적으로 가까워지는 방향을 찾는 지도 차원축소 방법이다. 특성 수 F, 클래스 수 C이면 보통 출력 차원 상한은 min(F,C−1)이며, 실제 데이터 행렬의 계수가 더 낮으면 유효한 방향 수는 더 적을 수 있다.

그림을 읽는 순서

먼저 축·색·연결 방향을 읽고, 각 그림 아래의 설명으로 확인하세요. 이어지는 손계산은 같은 개념을 다른 작은 숫자로 연습할 수도 있습니다.

숫자로 끝까지 따라가기

네 점의 두 열 합은 모두 0이므로 평균은 [0,0]이다. 첫 열 제곱합은 9+1+1+9=20, 둘째도 1+9+9+1=20이다. 두 열의 위치별 곱 합은 3+3+3+3=12다. 모집단 공분산 S=XᵀX/4는 [[5,3],[3,5]]다. S에 v₁=(1,1)/√2를 곱하면 (8,8)/√2=8v₁, v₂=(1,−1)/√2를 곱하면 (2,−2)/√2=2v₂다. 따라서 분산은 8과 2, 설명분산비는 8/(8+2)=0.8과 0.2다.

첫 좌표 t₁=(x₁+x₂)/√2는 [−4/√2,−4/√2,4/√2,4/√2]=[−2√2,−2√2,2√2,2√2]다. 둘째 좌표 t₂=(x₁−x₂)/√2는 [−√2,√2,−√2,√2]다. 정답을 x₁>x₂이면 1, 아니면 0으로 정의하면 y=[0,1,0,1]이다. t₁만 남기면 같은 입력 좌표에 서로 다른 정답이 섞인다. 두 점을 구분할 다른 정보가 없어졌으므로 어떤 결정적 모델도 이 네 점을 모두 맞힐 수 없다. t₂의 부호만 있으면 이 정답은 구분된다.

PYTHON · 작은 예제로 직접 확인
import numpy as np

X = np.array([[-3., -1.], [-1., -3.], [1., 3.], [3., 1.]])
mean = X.mean(axis=0)
centered = X - mean
S = centered.T @ centered / len(X)
V = np.array([[1., 1.], [1., -1.]]) / np.sqrt(2.)
projected = centered @ V
y = (X[:, 0] > X[:, 1]).astype(int)
variance = projected.var(axis=0)
print(S, projected, y, variance / variance.sum(), sep="\n")
assert np.allclose(variance, [8., 2.])
assert projected[0, 0] == projected[1, 0] and y[0] != y[1]
assert np.array_equal((projected[:, 1] > 0).astype(int), y)

비율 특성은 계산 가능한 조건도 확인해야 한다. 주행거리 120 km와 연료 6 L이면 120/6=20 km/L지만, 연료가 0이면 정의되지 않는다. 분모에 더하는 작은 ε는 0으로 나누는 것을 막기 위한 양수다. 다만 실제로 불가능한 기록을 ε로 덮으면 매우 큰 값이 생기므로, 분모 0이 무엇을 뜻하는지 먼저 확인한다. log1p(x)는 log(1+x)이며 실수 범위에서 x>−1이어야 하므로 음수 정답이나 특성에 무작정 적용하지 않는다.

시험 문제로 연결하기

PCA 차원 수는 누적 설명분산비뿐 아니라 검증 성능, 시간, 메모리를 함께 본다. 위 데이터에서 두 클래스와 두 입력인 LDA의 출력 상한은 min(2,1)=1이다. 한 축만 남긴다는 점은 PCA와 같아도 LDA는 정답을 사용하므로 선택할 방향이 달라질 수 있다. 특성 6개, 클래스 4개라면 상한은 min(6,3)=3이다. 클래스 평균 네 점의 독립적인 차이 방향이 최대 세 개라는 기하학적 생각으로 이해한다.

시계열 특성을 만들 때는 현재 시점에 무엇을 알 수 있는지부터 확인한다. 값 [10,14,13,20]의 네 번째 값을 예측할 때 바로 전 두 값의 평균은 (14+13)/2=13.5다. 현재 정답 20까지 포함한 (13+20)/2=16.5를 쓰면 다른 문제를 풀게 된다. 지연값(lag)은 일정 시점 전의 값을 붙인 열, 차분(difference)은 현재와 과거의 차이, 이동 통계(rolling)는 이동 구간마다 계산한 요약값이다. 미래 예측의 특성에 과거 값만 쓰려면 시간 정렬, 개체 구분, 값을 뒤로 미루는 시점을 함께 정해야 한다.

상관된 특성끼리는 중요도가 나뉘거나 하나가 다른 하나를 대신할 수 있으므로 개별 중요도를 인과 효과처럼 해석하면 안 된다. 필터 방식으로 각 열의 관계만 살피면 두 열의 조합에 담긴 정보를 놓칠 수 있다. 래퍼 방식은 모델을 반복 학습하므로 비용이 크고, 검증 데이터를 반복 이용하는 만큼 과적합 위험도 있다. L1 선택은 유용하지만 특성의 척도가 다르면 계수 크기의 비교도 달라지므로 전처리와 함께 설계한다.

주기적인 시각은 23시와 0시가 가깝다는 정보를 sin·cos 표현으로 줄 수 있고, 시계열의 FFT는 시간의 파동을 주파수별 성분으로 바꾸는 도구다. 그러나 어떤 주파수 구간 에너지를 쓸지 정하려면 샘플링 간격과 관측 창 길이를 알아야 한다. 이미지에서는 수동 특징을 잔뜩 추가하기 전에 크기·채널·정규화·정답 보존 증강을 맞추는 것이 먼저다. 특성 아이디어의 수가 아니라 생성 과정과 검증 근거로 선택한다.

새 특성을 만들었다면 원래 열만 사용한 결과와 한 번에 하나씩 비교한다. 비율, 과거 평균, 차원축소를 모두 동시에 추가해 점수가 올랐다면 무엇이 도움을 주었는지 알기 어렵다. 같은 분할에서 한 가지 변화를 더하거나 빼며 확인하는 비교를 제거 실험이라고 부른다. 성능뿐 아니라 추가 계산 시간과 결측 증가 여부도 기록하면 제한된 시간 안에서 유지할 특성을 합리적으로 고를 수 있다.

1. 특성 만들기·선택·추출은 서로 다른 작업이다

특성 공학은 원래 입력에서 문제에 맞는 새 특성을 만드는 작업이다. 거리·연료로 거리/연료 비율을 구하거나, 날짜에서 요일을 추출하거나, 이전 기록과의 변화량을 구하는 것이 예다. 특성 선택은 기존 열의 일부를 남기고, 특성 추출은 여러 열을 조합해 새 좌표를 만든다. 따라서 열 수가 줄었다는 결과만으로 둘을 구분할 수 없다. 온도·압력 중 온도만 남기면 특성 선택이고, 두 열의 합이나 차로 좌표 하나를 만들면 특성 추출이다.

필터 방식은 모델을 반복 학습하지 않고 특성별 분산이나 통계적 연관 등을 기준으로 고른다. 분산이 거의 0인 열을 제거하는 것은 정답을 쓰지 않는 필터 방식이다. 하지만 모든 필터 방식이 비지도인 것은 아니다. 정답과의 상관이나 카이제곱을 기준으로 쓰면 정답을 사용한다. 래퍼 방식은 여러 열 조합으로 특정 모델을 평가해 특성을 고른다. RFE는 모델 중요도가 낮은 열을 반복해서 제거한다. 내장형 방식은 L1이나 트리처럼 학습 과정의 계수나 분할 결과를 이용해 특성을 선택한다.

모델을 쓰는지만 외우면 래퍼 방식과 내장형 방식을 혼동하기 쉽다. 래퍼 방식은 평가 도구인 모델을 여러 번 호출하며 특성 부분집합을 찾는다. 내장형 방식에서는 모델 자체의 학습 목적이나 구조에서 선택 기준을 얻는다. 계산 비용, 상호작용을 찾는 능력, 해석의 용이성도 함께 비교한다. 필터 방식으로 열 하나씩만 보면 두 열이 함께 있을 때 나타나는 정보를 놓칠 수 있다. 래퍼 방식은 검증 데이터를 반복 사용하므로 우연히 좋은 조합을 고를 수 있다.

2. 계수 하나의 문제에서 L1의 최적값이 0이 되는 이유를 유도한다

“L1은 뾰족해서 0이 된다”를 수식으로 확인해 보자. 규제 없는 최적 계수 후보를 a라고 하고 목적함수 J(w)=0.5(w−a)²+λ|w|로 단순화한다. w는 찾을 계수, λ≥0은 벌점 강도다. w>0이면 |w|=w여서 미분 J'(w)=w−a+λ, 0인 후보는 w=a−λ다. 이 해가 양수이려면 a>λ여야 한다. w<0이면 |w|=−w여서 후보는 w=a+λ, 이 해가 음수이려면 a<−λ여야 한다.

나머지 −λ≤a≤λ에서는 양수 구간이나 음수 구간 안에 조건을 만족하는 최솟값이 없으므로, 꺾이는 지점 w=0이 최적이다. 정리하면 sign(a)max(|a|−λ,0)인 소프트 임계값 해다. sign은 양수에 1, 음수에 −1, 0에 0을 주는 부호 함수다. 이 식에서 일부 계수가 정확히 0이 되는 원리를 알 수 있다. 실제 여러 특성의 회귀에서는 계수 간 상호작용과 최적화 방법도 고려해야 하지만, 선택 효과의 기본 원리는 같다.

새 숫자로 a=0.3, λ=0.5이면 L1의 해는 0이다. a=1.8이면 해는 1.3이다. 같은 형태에 L2 규제항 (λ/2)w²를 쓰면 미분은 w−a+λw=0이고 해는 a/(1+λ)다. 앞의 두 후보는 0.2와 1.2로 줄지만 a≠0이면 정확히 0이 되지는 않는다. 같은 λ를 써도 두 규제항이 같은 함수는 아니라는 뜻이다. L1이 몇 개의 계수를 남길지, 선택한 열이 인과적으로 중요한지는 보장되지 않으며 상관된 열에서는 선택 결과가 불안정할 수 있다.

3. PCA의 분산 비율은 정답 정보의 비율이 아니다

입력 네 점을 [−10,−1], [−10,1], [10,−1], [10,1]로 두자. 두 열 평균은 0이고 모집단 분산은 첫 열 100, 둘째 1, 공분산 0이다. 공분산 행렬은 [[100,0],[0,1]]이며 PCA 첫 축은 가로 방향, 설명분산비는 100/101≈99.01%다. 누적 95%만 남기라는 기준이면 가로 한 축만 남길 수 있다.

둘째 좌표가 양수이면 정답을 1, 음수이면 0으로 정하면 정답은 [0,1,0,1]이다. 가로축만 남기면 −10에도 정답 0·1이 모두 있고, +10에도 0·1이 모두 있다. 같은 입력에 항상 같은 결과를 내는 분류기는 같은 숫자에 서로 다른 정답을 동시에 부여할 수 없으므로 네 점을 모두 구분할 정보가 사라진 것이다. 입력 분산을 99% 이상 보존했지만 이 정답을 구분하는 핵심 정보는 잃었다. 반대로 둘째 축 하나만 남기면 부호만으로 완벽하게 구별된다.

PCA의 설명분산비는 얼마나 압축했는지 판단하는 근거이고, 검증 성능은 정답 예측에 유용한지 판단하는 근거다. 같은 단위에서도 분산이 작은 방향이 측정 잡음일 수도 있고 중요한 차이일 수도 있다. 표준화하면 두 열의 상대적인 분산이 바뀌므로 PCA 결과도 달라진다. 이 예제의 성공이나 실패를 모든 데이터에 일반화하지 말고, 목적함수가 무엇을 기준으로 삼는지 이해한다. PCA는 정답을 사용하지 않는다.

4. LDA 차원 상한 C−1은 클래스 평균의 차이에서 나온다

LDA 차원축소는 서로 다른 클래스 평균의 차이가 크고 각 클래스 내부 퍼짐이 상대적으로 작은 방향을 찾는다. 특성 수 F는 원래 공간의 축 수, 클래스 수 C는 정답 종류 수다. 클래스가 2개면 평균 점 두 개를 잇는 차이 방향은 하나다. 클래스가 3개면 평균 점 세 개가 만드는 독립적인 차이는 최대 두 방향이다. 한 평균을 기준점으로 삼으면 다른 평균의 차이 벡터가 C−1개뿐이라는 점이 일반 상한을 설명한다.

더 엄밀하게 전체 평균 μ와 클래스 평균 μ_c의 차이를 보면, 표본 수 n_c로 가중한 합은 Σ_c n_c(μ_c−μ)=0이다. 따라서 C개의 차이 벡터에는 선형 종속 관계가 적어도 하나 있다. 클래스 간 산포 행렬 S_B=Σ_c n_c(μ_c−μ)(μ_c−μ)ᵀ의 계수는 최대 C−1이며, 원래 공간의 차원 F도 넘을 수 없으므로 유효 차원의 상한은 min(F,C−1)이다. 클래스 내부 산포 S_W는 각 관측값과 해당 클래스 평균의 차이로 만든다. 방향 v의 기준은 (vᵀS_Bv)/(vᵀS_Wv)처럼 클래스 내부의 퍼진 정도에 비해 평균들이 얼마나 떨어져 있는지 나타내는 비율로 이해할 수 있다.

예를 들어 특성이 8개이고 클래스가 3개이면 최대 min(8,2)=2차원이다. 특성이 2개이고 클래스가 5개이면 최대 2차원이다. 하지만 다섯 클래스의 평균이 모두 같은 직선 위에 있으면 실제로 구분에 유효한 방향은 하나일 수 있다. 상한이 정해져 있다고 언제나 그만큼 유익한 축을 얻는 것은 아니다. 내부 산포 행렬이 특이하거나 표본 수가 적으면 안정화 방법과 해를 구하는 알고리즘의 조건도 중요하다. 정답을 쓰는 지도학습 방법이므로 분할 후 학습 데이터로만 학습한다.

5. 파생변수의 정의역과 관측 시점을 함께 확인한다

거리 150 km, 연료 5 L의 비율은 30 km/L다. 연료가 0이면 수식은 정의되지 않는다. 분모에 작은 양수 ε를 넣어 실행을 가능하게 만들어도 불가능한 기록의 의미가 해결된 것은 아니다. log1p(x)=ln(1+x)는 실수에서 x>−1이 필요하다. 0을 허용한다고 모든 음수를 허용하지 않는다. 날짜의 시간대처럼 주기적인 특성은 23시와 0시가 가깝다는 구조를 sin·cos로 표현할 수 있지만 어떤 표현도 새 정보가 저절로 생기는 것은 아니다.

시계열 값이 [4,6,8,10,12]이고 네 번째 값 10을 예측해야 한다면 이미 관측한 직전 두 값의 평균은 (6+8)/2=7이다. 현재 정답 10을 포함해 (8+10)/2=9를 만들면 정답 일부가 입력에 들어간다. 반대로 네 번째 값을 관측한 뒤 다섯 번째 값을 예측하는 조건이라면 10을 사용할 수 있다. 지연값은 과거 값을 뒤로 옮겨 붙인 열이고 이동 통계는 구간의 요약값이다. shift가 어느 시점의 값을 입력에 붙이는지 명확히 해야 한다.

center=True인 이동 구간은 현재 위치의 양쪽을 사용하므로, 미래 예측에서는 아직 관측하지 못한 뒤쪽 값이 포함될 수 있다. 전체 차량 평균도 정답을 전혀 사용하지 않았더라도 미래 운행의 센서 값을 포함하면 위험하다. 정답 사용 여부, 예측 시점의 정보 사용 가능성, 같은 그룹 안에서 계산했는지를 각각 검사한다. 단순한 분산 필터도 전처리 선택 기준이므로 학습 데이터에서 정하고 검증 데이터에는 그대로 적용한다. 전체 데이터를 먼저 압축한 뒤 교차검증하면 평가용 정보가 변환 기준에 들어갈 수 있다.

특성 선택의 계열은 scikit-learn feature selection, L1과 L2의 목적함수는 linear models, 클래스 평균으로 얻는 차원 상한은 LDA dimensionality reduction을 참고한다. 계수 하나의 L1 계산과 네 점의 PCA 계산은 원리를 설명하기 위해 새로 만든 예제다.

9.2 특성 만들기

좋은 특성은 모델이 배워야 할 관계나, 조건이 달라져도 유지되는 성질을 입력에 미리 반영한다.

표형:

  • 비율 a/(b+eps), 차이 a-b, 곱 a×b
  • log1p 변환, 제곱, 구간 나누기
  • 날짜에서 시간·요일·월 추출
  • 범주별 빈도

시계열:

  • 과거 구간의 평균·표준편차·최솟값·최댓값·기울기
  • 과거 시점의 값과 차분
  • 이동 구간별 통계
  • FFT 주파수 대역별 에너지 등의 주파수 특징

이미지:

  • CNN을 쓴다면 윤곽선 특성을 직접 만들기보다 크기 조정·정규화·증강을 올바르게 적용하는 일이 먼저다.

[함정] 이동 구간 통계나 집계값은 반드시 해당 예측 시점 이전의 데이터만 사용해 구한다. center=True로 계산하는 이동 통계나 전체 그룹 평균에는 미래 정보가 포함될 수 있다.

9.3 특성 선택의 세 계열

계열 예 장점 단점
필터 방식 분산, 상관관계, 카이제곱, 상호정보량 빠르고 모델에 의존하지 않음 특성 간 상호작용을 놓칠 수 있음
래퍼 방식 RFE, 순차 선택 모델 성능을 직접 반영 계산 비용이 크고 과적합 위험이 있음
내장형 방식 L1, 트리 중요도 학습하면서 특성을 선택 사용하는 모델의 특성에 영향을 받음

특성 선택은 원래 특성의 일부를 그대로 남기므로 해석하기 좋다. 특성 중요도가 높다고 인과관계가 있다는 뜻은 아니며, 서로 상관된 특성 사이에 중요도가 나뉠 수 있다.

9.4 PCA 상세

PCA는 분산이 큰 방향부터 서로 직교하는 축을 골라 데이터를 투영한다. 입력의 척도에 민감하며 정답은 사용하지 않는다.

설명분산비의 누적합으로 차원을 정할 수 있지만, 최종 판단 기준은 검증 성능과 시간·메모리다. 분산을 95% 보존한다고 예측에 필요한 정보도 95% 보존하는 것은 아니다. 분산이 작은 방향이 정답 예측에 중요할 수 있다.

PYTHON 예시
from sklearn.decomposition import PCA
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

pca_pipe = Pipeline([
    ("scale", StandardScaler()),
    ("pca", PCA(n_components=0.95, random_state=42)),
])
Xtr_pca = pca_pipe.fit_transform(X_train_num)
Xva_pca = pca_pipe.transform(X_valid_num)

9.5 LDA 차원축소

선형 판별 분석(LDA)은 클래스 간 분산은 크게, 클래스 내부 분산은 작게 만드는 축을 찾는다. 특성 수가 F이고 클래스 수가 C이면 일반적인 구현의 출력 차원 상한은 min(F, C-1)이다. 표본 수와 산포 행렬의 계수 제약 때문에 실제 유효 차원은 더 작을 수도 있다. 정답을 사용하는 지도학습 방법이므로 반드시 분할 후 학습 데이터로만 학습한다.

9.6 데이터 누수 없는 파생변수

개체별 정답 평균을 쓰는 타깃 인코딩이나 집계 특성은 특히 누수에 주의해야 한다.

  • 평가 시점에 실제로 얻을 수 있는 값인가?
  • 현재 행의 정답이나 미래 행을 포함하는가?
  • 검증 그룹의 통계가 학습 특성에 들어가는가?
  • 이동 구간 통계를 과거 정보만으로 계산하는가?

하나라도 문제가 발견되면 특성을 다시 정의한다.

9.7 실습문제

  1. 분산이 거의 0인 특성을 제거하는 방법은 세 계열 중 어디에 속하는가?
    풀이에 필요한 이론

    특성 만들기·선택·추출은 서로 다른 작업이다

  2. L1 선형모델이 특성을 선택하는 효과를 갖는 이유는?
    풀이에 필요한 이론

    계수 하나의 문제에서 L1의 최적값이 0이 되는 이유를 유도한다

  3. 입력 특성이 6개이고 클래스가 4개인 LDA의 최대 출력 차원은?
    풀이에 필요한 이론

    LDA 차원 상한 C−1은 클래스 평균의 차이에서 나온다

  4. rolling(window=10, center=True)가 미래 예측에서 위험한 이유는?
    풀이에 필요한 이론

    파생변수의 정의역과 관측 시점을 함께 확인한다

  5. PCA가 분산의 95%를 설명한다는 것과 예측 정보의 95%를 보존한다는 것이 다른 이유는?
    풀이에 필요한 이론

    PCA의 분산 비율은 정답 정보의 비율이 아니다

정답·해설 보기
  1. 정답을 보지 않는 필터 방식.
  2. L1 규제항은 0에서 매끄럽지 않으므로 일부 계수가 정확히 0이 되기 쉽다.
  3. min(F,C-1)=min(6,3)=3.
  4. 현재 시점의 앞뒤 값을 모두 사용하므로 미래 관측값이 특성에 포함된다.
  5. PCA는 정답과 무관하게 X의 분산을 보존한다. 따라서 정답 예측에 중요한 저분산 방향을 버릴 수 있다.
