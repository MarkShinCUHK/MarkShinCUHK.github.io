먼저 떠올릴 장면

흑백 사진은 밝기 숫자를 격자로 놓은 배열이다. 한 칸이 픽셀이고, 값이 크면 밝다는 식의 표현 규칙을 쓴다. 사진에서 작은 경계를 찾으려면 이웃한 픽셀 사이의 밝기 차이를 보면 된다. 예를 들어 나란한 값 [1,4]에 계수 [−1,1]을 곱해 더하면 −1+4=3이다. 둘이 같은 밝기 [4,4]면 0이다. 작은 창의 계산 결과가 그 위치의 무늬에 대한 반응이 되는 것이다.

CNN의 합성곱 층은 이런 작은 창의 가중치를 모든 위치에서 공유한다. 왼쪽에서 찾던 경계가 오른쪽에 나타나도 같은 검사 규칙을 적용한다. 창을 한 번 놓아 얻은 숫자 하나는 전체 사진의 클래스가 아니다. 창을 옮기며 얻은 반응들을 공간 위치대로 모은 배열이 특징 지도다. 앞 층의 특징 지도를 다음 층이 읽고, 마지막에 그 정보를 요약해 정상·불량 같은 예측을 만든다.

실제 필터의 계수는 보통 사람이 경계 검출기로 고정하지 않고 정답과 손실을 이용해 학습한다. 그러므로 채널 하나를 반드시 ‘바퀴 찾기’처럼 이름 붙일 수는 없다. 우리가 확인할 것은 입력에서 출력 한 칸이 어떻게 만들어지고, 같은 규칙이 몇 번 사용되며, 그 결과가 다음 층에 어떤 형태로 전달되는가다. 작은 곱셈부터 시작하면 채널 수와 이미지 크기를 혼동하지 않게 된다.

낯선 말부터 풀기

채널은 같은 위치에 나란히 놓인 값의 종류다

RGB 사진의 한 픽셀에는 빨강·초록·파랑 세 값이 있다. 가로세로가 같은 세 장의 숫자 지도를 겹쳐 놓았다고 생각하면 입력 채널 3의 의미가 보인다. 그런데 합성곱 뒤 채널 8은 색이 여덟 개라는 뜻이 아니다. 서로 다른 필터 여덟 개의 반응 지도다. [B,8,H,W]의 같은 높이·너비 위치에 여덟 종류의 반응값이 놓인다.

groups=1에서 필터 하나는 입력 채널 전체를 읽는다. 1×1 창의 두 입력 채널 값이 2와 5, 첫 필터 계수가 3과 −1, 편향 0이면 출력은 3×2−1×5=1이다. 둘째 필터 계수가 1과 1이면 출력은 7이다. 입력 두 채널에서 출력 두 채널을 만들었지만, 첫 채널을 그대로 복사하고 둘째를 그대로 복사한 것이 아니다. 각 필터가 두 입력을 다르게 섞었다. Stanford CS231n 합성곱 노트의 ‘공간에는 작은 연결, 채널에는 전체 연결’이라는 구분을 이렇게 숫자로 읽는다.

채널(channel)은 같은 공간 위치에 있는 값의 종류다. RGB 입력이면 C=3이고, 출력 채널 수는 서로 다른 필터의 수다. 커널(kernel)은 작은 검사창의 가중치 배열이고, 스트라이드(stride)는 창의 이동 간격, 패딩(padding)은 가장자리 바깥에 추가하는 영역, 팽창 간격(dilation)은 커널 원소 사이의 간격이다. 수용 영역(receptive field)은 한 출력값이 원래 입력의 어느 범위에 의존하는지를 말한다. 여러 층을 쌓으면 커널 하나의 크기와 네트워크 전체의 수용 영역은 달라진다.

PyTorch Conv2d의 배치 입력 형태는 [B,C,H,W]다. B는 배치 표본 수, C는 채널 수, H와 W는 높이와 너비다. 이미지 로더가 준 [H,W,C] 배열은 축을 재배열해야 한다. 스트라이드나 패딩을 바꾸면 공간 크기는 변하지만 학습할 커널 개수는 그대로일 수 있다. 일반적인 딥러닝 라이브러리의 합성곱 연산은 수학적 합성곱과 달리 커널을 뒤집지 않는 상호상관(cross-correlation)으로 구현된다. 용어와 가중치 공유의 원리는 Stanford CS231n 합성곱 강의가 설명한다.

필터의 숫자와 특징 지도의 숫자는 같은 것이 아니다

입력 3×3 위에 2×2 창을 왼쪽 위부터 놓자. 같은 위치끼리 곱하고 네 곱을 더해 출력 한 칸을 쓴다. 창을 오른쪽으로 한 칸 옮겨도 필터 계수는 그대로다. 달라지는 것은 필터 아래 들어온 입력값이다. 출력 칸을 네 개 만들었다고 서로 다른 필터 네 개를 학습하는 것은 아니다. 필터 네 계수는 파라미터이고, 출력의 네 값은 이번 입력에서 만든 활성값이다.

패딩 0이면 창이 입력 밖으로 나가지 않도록 배치하고, 패딩 1이면 가장자리 바깥에 한 겹의 칸을 추가한다. 스트라이드 2이면 시작점을 한 칸이 아니라 두 칸씩 옮긴다. 팽창 간격 2이면 계수 사이가 한 칸씩 벌어져 더 넓은 입력 영역을 본다. 그림의 색칠된 범위를 따라 이 세 변화가 ‘보는 위치’를 어떻게 바꾸는지 확인한다.

핵심 기억 — 입력 채널은 위치별 값 종류, 필터는 학습 계수, 특징 지도는 필터를 여러 위치에 적용한 결과다.

출력 길이 공식은 창을 놓을 시작점 개수를 센다

입력 길이 7, 창 길이 3, 패딩 0, 스트라이드 2라면 시작점을 0, 2, 4에 놓을 수 있다. 시작점 4의 창은 4·5·6을 보고, 다음 시작점 6은 6·7·8을 보려 하므로 범위를 벗어난다. 출력 길이는 3이다. 일반적으로 패딩 후 길이에서 창이 실제 덮는 폭을 뺀 만큼 시작점을 이동할 수 있고, 그 거리를 스트라이드로 나누어 센 뒤 최초 위치 하나를 더한다. 소수 부분을 버리는 floor는 마지막 불완전한 이동을 세지 않기 위해 필요하다. 아래 일반식에서 팽창을 고려한 실제 폭이 D(K−1)+1인 것도 이 배치 규칙 때문이다.

아래 작은 입력과 커널은 그림과 같은 연산을 다른 숫자로 검산하기 위한 독립 예다.

입력이 [[1,2,3],[4,5,6],[7,8,9]], 커널이 [[1,0],[0,−1]], 편향=0, 스트라이드=1, 패딩=0이라고 하자. 왼쪽 위 출력은 1×1+2×0+4×0+5×(−1)=−4다. 오른쪽 위는 2−6=−4, 왼쪽 아래는 4−8=−4, 오른쪽 아래는 5−9=−4다. 따라서 2×2 출력이 모두 −4다. 이 뒤 ReLU를 붙이면 모두 0이 된다. 합성곱과 활성함수 적용을 한 연산으로 뭉뚱그리지 말고 중간 결과를 확인한다.

한 공간축 출력 크기를 floor((I+2P−D(K−1)−1)/S+1)로 계산한다. I는 입력 길이, P는 패딩, D는 팽창 간격, K는 커널 길이, S는 스트라이드다. I=7, K=3, P=1, S=2, D=1이면 floor((7+2−2−1)/2+1)=4다. 높이와 너비 각각 계산한다. 출력이 항상 I/S라는 요약은 일반식이 아니다.

3채널 입력에서 3×3 필터 4개를 사용하고 편향이 있으면 필터 하나당 3×3×3+1=28개, 총 112개 파라미터다. 입력 사진이 32×32인지 64×64인지에 따라 이 수가 달라지지 않는다. 반면 출력 활성값의 수는 공간 크기에 따라 달라져 메모리와 연산량은 증가한다. 풀링 입력이 [[1,4],[2,3]]이면 2×2 최대 풀링은 4, 평균 풀링은 2.5다. 어느 연산인지에 따라 보존하는 정보가 다르다.

PYTHON · 작은 예제로 직접 확인
import torch
import torch.nn.functional as F

x = torch.arange(1., 10.).reshape(1, 1, 3, 3)
kernel = torch.tensor([[[[1., 0.], [0., -1.]]]])
out = F.conv2d(x, kernel, stride=1, padding=0)
print("conv output:", out)
assert out.shape == (1, 1, 2, 2)
assert torch.allclose(out, torch.full_like(out, -4.))
patch = torch.tensor([[[[1., 4.], [2., 3.]]]])
print("max/mean:", F.max_pool2d(patch, 2).item(),
      F.avg_pool2d(patch, 2).item())
conv = torch.nn.Conv2d(3, 4, kernel_size=3, bias=True)
assert sum(p.numel() for p in conv.parameters()) == 112

시험 문제로 연결하기

작은 특징 지도는 어떻게 최종 분류로 이어질까

한 채널의 2×2 반응이 [[1,4],[2,3]]이면 최대 풀링은 가장 강한 4를 남기고 평균 풀링은 (1+4+2+3)/4=2.5를 남긴다. 두 경우 모두 값 네 개가 하나로 줄어 다음 계산량은 줄지만 위치별 세부 정보는 사라진다. 입력 [[4,1],[3,2]]도 같은 최대·평균을 내므로 풀링 결과만으로 원래 배열을 복원할 수 없다.

이런 요약을 각 채널에서 수행하고 Linear 헤드에 전달한다. 예를 들어 여덟 채널 각각을 평균 하나로 줄이면 이미지 한 장이 특징 여덟 개가 된다. 그 여덟 값에 학습 계수를 곱해 클래스 점수를 계산하는 마지막 단계는 MLP와 같다. 합성곱은 공간 패턴을 만드는 부분, 풀링은 요약하는 부분, 헤드는 요구된 예측으로 바꾸는 부분으로 연결된다.

이미지 자르기(crop)의 좌표는 CNN의 텐서 형태 문제와 연결된다. PIL의 자르기 영역인 box는 (left, upper, right, lower)이고 오른쪽·아래쪽 끝을 포함하지 않는다. 예를 들어 (10,20,50,70)이면 너비는 50−10=40, 높이는 70−20=50이다. RGB 배열은 이 경우 [50,40,3], PyTorch 단일 이미지 텐서는 [3,50,40]다. 너비와 높이 순서를 거꾸로 적지 않는다. 적응형 풀링(adaptive pooling)이 서로 다른 H/W를 받는다고 DataLoader가 크기가 다른 이미지를 자동으로 같은 배치에 쌓아 주는 것도 아니다. 표본을 배치로 묶는 기본 처리(collate)를 사용하려면 이미지 크기를 같게 조정하거나 패딩하는 처리가 필요하다.

CNN의 텐서 형태 문제는 각 층의 [B,C,H,W]를 한 줄씩 써서 푼다. 합성곱 층은 출력 채널 수를 out_channels로 바꾸고, 풀링은 보통 채널 수를 유지하며 H/W를 줄인다. [B,16,8,8]을 배치 축을 남겨 펼치면 [B,1024]이고 Linear 입력 차원은 1024다. AdaptiveAvgPool2d((1,1))를 넣으면 [B,16,1,1], 펼친 뒤에는 [B,16]이 되어 공간 크기에 덜 의존하는 예측 헤드를 만들 수 있다.

이미지를 실수형으로 바꿔 255로 나누는 척도 조정과 채널별 평균·표준편차를 이용한 정규화는 다른 단계다. 이미 0부터 1 사이인 입력을 다시 255로 나누면 값이 지나치게 작아진다. NumPy HWC를 CHW로 바꿀 때는 reshape가 아니라 transpose/permute를 사용한다. 증강은 정답이 유지되는 변형인지 먼저 판단하고 훈련에서만 무작위로 적용한다. 좌우 반전이 문자나 좌우를 구분하는 정답을 바꾸는 과제라면 안전한 증강이 아닐 수 있다.

자주 헷갈리는 지점

픽셀 수가 늘어도 같은 필터를 더 많이 사용한다

3×3 입력을 2×2 필터 하나로 처리하면 출력은 2×2지만, 4×4 입력이면 3×3 출력이다. 필터의 네 계수와 편향 하나는 그대로 다섯 개다. 계산 결과를 저장할 칸과 같은 곱셈을 반복할 횟수가 늘었을 뿐이다. 반대로 필터 수를 두 배로 늘리면 보통 출력 채널과 학습할 계수 수도 늘어난다. 파라미터 메모리와 활성값 메모리를 따로 세어야 큰 이미지에서 메모리가 부족한 이유를 설명할 수 있다.

필터 하나는 일반적으로 입력 채널 전체를 함께 읽는다. 일반적인 groups=1 Conv2d의 파라미터 수는 C_out×C_in×K_h×K_w+C_out이며, 그룹 설정에 따라 연결되는 입력 채널 수가 달라진다. 풀링에는 보통 학습할 가중치가 없지만 정보 손실은 있다. CNN에는 입력 위치가 이동하면 출력도 그에 맞춰 이동하는 등변성(equivariance)이 있다. 하지만 패딩·스트라이드·풀링·가장자리의 효과까지 고려하면 모든 위치 이동에 완전히 같은 분류 결과를 보장하지 않는다. 커널 크기 3인 층을 두 개 쌓고 stride=1로 두면 이론적 수용 영역은 5가 되므로 ‘각 층이 3만 보니 전체도 3만 본다’는 해석도 틀리다.

흔한 오해 — 합성곱은 위치별 반응을 만들며 이동 불변 분류를 무조건 보장하지 않는다. 패딩·stride·pooling과 가장자리 조건도 결과에 영향을 준다.

정의와 유도 과정부터 문제 풀이까지

필기 이론: 정의에서 풀이까지

공식에 쓰인 기호가 무엇을 뜻하는지, 어떤 조건에서 그 공식을 쓸 수 있는지 설명합니다. 실습문제와 다른 숫자를 넣은 예제로 계산 과정을 익힙니다. 각 절 끝에는 이 개념을 적용할 문제로 돌아가는 링크가 있습니다.

1. 작은 커널의 가중치를 모든 위치에서 재사용한다

사진 왼쪽의 세로 경계와 오른쪽의 세로 경계를 찾는 데 위치마다 새 검출기를 배울 필요는 없다. 작은 가중치 창 하나를 옮기며 같은 계산을 반복하는 것이 합성곱의 출발점이다. 입력의 작은 조각에 커널을 겹쳐 같은 위치끼리 곱하고 더한 값 하나를 만든다. 창을 옮겨 얻은 값들을 모으면 특징 맵이다. 아래 예에서는 가중치 네 개를 새로 고르는 것이 아니라 같은 네 개를 네 위치에서 재사용한다.

MLP는 입력 위치마다 서로 다른 가중치를 둘 수 있지만 합성곱(convolution)은 작은 창을 옮겨 가며 같은 가중치를 공유한다. 커널(kernel)은 그 창에 적용하는 가중치 배열이고, 특징 맵(feature map)은 각 위치의 계산 결과를 모은 배열이다. RGB 이미지에서는 같은 픽셀 위치에 R·G·B 세 값이 있으므로 입력 채널 수 C_in=3이다. 일반적인 groups=1 설정에서 필터 하나는 이 입력 채널 전체를 사용해 출력 채널 하나를 만든다. 출력 채널 수 C_out은 서로 다른 필터의 수다.

손계산 예 A: 입력은 [[2,1,0],[1,3,2],[0,2,4]], 커널은 [[1,−1],[0,1]]이고 bias=1, stride=1이라고 하자. 왼쪽 위 창 [[2,1],[1,3]]의 계산은 2−1+0+3+1=5다. 오른쪽 위는 1−0+0+2+1=4, 왼쪽 아래는 1−3+0+2+1=1, 오른쪽 아래는 3−2+0+4+1=6이다. 결과는 [[5,4],[1,6]]이다. 같은 네 커널 값과 편향을 모든 위치에서 재사용했다.

PyTorch의 일반적인 Conv 연산은 커널을 뒤집지 않는 교차상관(cross-correlation)이며 위 계산이 그 방식이다.

같은 가중치를 공유하므로 입력 무늬를 옮기면 그에 반응하는 출력 위치도 따라 움직이는 이동 등변성(translation equivariance)을 기대할 수 있다. 이는 입력이 이동해도 출력이 그대로인 불변성(invariance)과 다르다. 보폭, 패딩 경계, 풀링은 이 성질을 제한할 수 있다. 하나의 합성곱은 작은 창 안의 정보만 사용하므로 층을 깊게 쌓아 더 넓은 영역의 정보를 결합한다. CNN에 OpenCV가 필수인 것은 아니다. Pillow로 이미지를 읽어 배열이나 텐서로 준비하고, 학습 가능한 합성곱은 PyTorch로 수행할 수 있다.

2. 출력 크기 공식은 창을 몇 번 놓는지 세는 식이다

길이 7인 줄에 폭 3인 창을 두 칸씩 옮겨 놓으면 시작점은 0·2·4의 세 곳이다. 시작점 6에서는 창이 줄 밖으로 나간다. 그래서 출력 길이는 3이다. 아래의 floor는 이런 마지막에 남은 불완전한 이동을 버리는 연산이다. 먼저 팽창률까지 반영한 실제 창 폭을 구하고, 패딩으로 늘어난 줄에서 창을 놓을 수 있는 시작점을 센다. 몫이 정수가 아니어도 PyTorch의 일반 합성곱은 바닥 함수를 적용해 유효한 출력 크기를 정할 수 있다.

한 축의 입력 길이를 I, 양쪽 패딩을 P, 커널 길이를 K, 팽창률(dilation)을 D, 보폭(stride)을 S라고 하자. 팽창률은 커널 원소 사이의 간격을 벌리는 정도다. 실제로 덮는 폭은 K_eff=D(K−1)+1이다. 패딩을 추가한 뒤 총길이는 I+2P이고 창의 시작점은 0,S,2S,…이다. 마지막 시작점이 I+2P−K_eff를 넘으면 안 되므로 창의 개수는 floor((I+2P−K_eff)/S)+1이다. 이를 전개하면 기존 출력 공식 floor((I+2P−D(K−1)−1)/S+1)이 나온다.

손계산 예 B: I=13,K=3,D=2,P=2,S=2이면 K_eff=5이고 패딩을 추가한 길이는 17이다. 시작점은 0,2,4,6,8,10,12로 일곱 개다. 공식으로 계산해도 floor((17−5)/2)+1=7이다. ‘입력 길이의 절반’만 계산하면 6.5여서 답을 결정할 수 없다. 높이와 너비가 다르면 각 축에 독립적으로 적용한다. 출력 크기가 같더라도 팽창률, 보폭, 패딩이 다르면 참조하는 위치와 경계에서 사용하는 정보가 달라진다.

stride=1에서 K_eff가 홀수이고 P=(K_eff−1)/2이면 공간 길이를 유지할 수 있다. 하지만 stride가 2이면 같은 패딩을 사용해도 원래 길이가 보존되지 않는다. 팽창률을 키운다고 학습 가중치가 추가되는 것도 아니다. 3개 가중치 사이의 간격이 넓어졌을 뿐 학습할 숫자는 여전히 3개다.

3. 그룹 수·파라미터 수·활성값 수를 구분한다

RGB 입력에서 필터 하나는 빨강·초록·파랑의 가중치를 함께 사용해 출력 채널 하나를 만든다. 출력 채널 12개라면 그런 필터가 12개다. 그룹 합성곱은 모든 입력 채널을 연결하는 대신 정해진 묶음 안에서만 연결한다. 따라서 아래 식의 C_in/groups는 필터 하나가 실제로 읽는 입력 채널 수다. 이미지가 커져 필터를 더 많이 옮겨도 보관할 가중치가 늘지는 않지만 계산 결과를 저장할 공간은 늘어난다.

일반적인 Conv2d의 가중치 배열 크기는 [C_out,C_in/groups,K_h,K_w]다. groups=G이면 입력·출력 채널을 G개 묶음으로 나누어 각 묶음 안에서만 연결한다. C_in과 C_out은 모두 G로 나누어떨어져야 한다. 편향이 있으면 출력 채널마다 하나를 더하므로 파라미터 수는 C_out×(C_in/G)×K_h×K_w+C_out이다. 공간 크기 H·W와 배치 크기 B는 이 식에 없다. 같은 필터를 반복 사용하는 횟수를 파라미터 수에 다시 곱하지 않는다.

입력이 6채널, 출력이 12채널이고 커널이 3×3, groups=3, bias=True라면 필터당 가중치는 2×3×3=18개다. 전체는 12×18+12=228개다. groups=1이면 12×6×9+12=660개다. 깊이별 합성곱(depthwise)은 groups=C_in인 특별한 연결 방식이며, 출력 채널 수가 입력 채널 수의 정수배일 수 있다. 1×1 합성곱도 입력 채널을 섞으므로 학습할 값이 있다. ‘픽셀 하나만 사용하므로 아무 계산도 하지 않는다’고 생각해서는 안 된다.

출력 크기가 [B,12,7,7]이면 활성화 값은 B×12×49개다. B나 이미지 크기가 커지면 활성화 값을 저장하는 메모리와 곱셈 횟수는 늘지만 위 가중치 개수는 그대로다. 모델 파라미터 수, 한 번의 순전파에서 만들어지는 중간값 수, 계산량을 서로 구분해서 세는 습관이 필요하다.

4. 풀링과 수용 영역을 단계별로 계산한다

작은 영역에서 가장 강한 반응 하나만 남기면 최대 풀링이고, 평균적인 반응을 남기면 평균 풀링이다. 어느 값을 남길지는 규칙으로 정해져 있어 일반적인 풀링에는 학습 가중치가 없다. 수용 영역은 다른 질문이다. 이 출력 하나에 원본의 어디까지 영향을 줄 수 있는가를 묻는다. 앞층에서 두 칸씩 건너뛴 출력들을 뒷층이 읽으면 원본 기준의 간격도 두 배이므로, 커널 크기뿐 아니라 출력 사이 간격 j를 함께 기록해야 한다.

MaxPool은 창 안의 최댓값을, AveragePool은 평균을 취한다. 일반적인 최대 풀링, 평균 풀링, 적응형 풀링에는 학습 가능한 가중치가 없다. 입력 [[2,8],[4,6]]의 2×2 MaxPool은 8, AveragePool은 5다. 채널별로 공간 정보를 요약하므로 보통 채널 수는 유지된다. AdaptiveAvgPool2d(1)은 공간 크기에 상관없이 각 채널을 값 하나로 만들어 [B,C,1,1]을 반환한다. 이어 배치 축을 보존하면서 펼치면 [B,C]가 된다. 입력을 자동으로 같은 크기로 만들어 배치에 쌓아 주는 기능은 아니다.

수용 영역(receptive field) r은 출력 하나가 원본에서 참조할 수 있는 이론적인 범위의 폭이다. 출력 간격(jump) j는 이웃한 두 출력의 위치 간격을 원본 기준으로 나타낸 값이다. 시작은 r=1,j=1이다. 커널 길이가 K, 팽창률이 D, 보폭이 S인 층을 지날 때 r_new=r+(K−1)D×j, j_new=j×S다. 먼저 커널 길이가 3이고 보폭이 1인 합성곱을 거치면 r=3,j=1이다. 이어 커널 길이가 2이고 보폭이 2인 풀링을 거치면 r=4,j=2이며, 다음으로 커널 길이가 3이고 보폭이 1인 합성곱을 거치면 r=8,j=2다.

마지막 커널의 길이가 3이라고 원본에서 3칸만 참조한다는 말은 틀리다. 패딩 위치나 실제 가중치에 따른 유효 영향 범위와 이론적인 최대 범위도 구별한다.

5. 이미지 좌표와 텐서의 축을 놓치지 않는다

사진의 위치를 “오른쪽으로 4, 아래로 7”이라고 말할 때는 x·y 순서지만, 표처럼 저장한 배열은 먼저 몇 번째 행인지, 다음에 몇 번째 열인지를 고른다. 그래서 Pillow의 너비·높이와 배열의 높이·너비 순서가 다르다. 아래 자르기 예는 끝 좌표를 포함하지 않으므로 너비가 19−4=15, 높이가 28−7=21이다. 그 뒤 이미지 읽기 → 값 범위 확인 → 채널 축 이동 → 배치로 묶기를 각각 별도 단계로 확인한다.

Pillow의 자르기 영역은 (left,upper,right,lower)로 지정하며 끝 좌표 right·lower는 제외한다. 예를 들어 (4,7,19,28)의 너비는 15, 높이는 21이다. RGB 배열의 크기는 [21,15,3]이고, PyTorch Conv에 넣는 이미지 하나의 크기는 [3,21,15]다. B개를 모으면 [B,3,21,15]다. Pillow의 size는 보통 (width,height) 순서이지만 배열 크기를 나타낼 때는 높이가 먼저이므로 두 순서를 따로 기억한다.

배치 이미지의 축 순서를 [B,H,W,C]에서 [B,C,H,W]로 바꾸려면 permute(0,3,1,2)를 쓴다. reshape는 메모리에 있는 원소를 새로운 배열 크기로 해석하는 연산이므로 축 순서를 바꾸는 연산을 대신할 수 없다. 0부터 255까지의 8비트 이미지를 float32로 바꿔 255로 나누는 단계와 채널별 평균·표준편차로 정규화하는 단계는 별개다. 이미 0부터 1인 입력을 또 255로 나누면 값이 의도보다 작아진다. 배열 크기와 자료형 외에도 값의 범위를 확인해야 한다.

19.2 합성곱의 원리

길이 4 입력 [1,2,4,7]에 커널 [1,−1]을 한 칸씩 적용해 보자. 첫 두 값에서 1−2=−1, 다음에서 2−4=−2, 마지막에서 4−7=−3이다. 같은 두 가중치를 계속 재사용하며 이웃 값의 변화에 반응하는 결과 세 개를 만들었다. 이미지에서는 이 창을 가로·세로로 움직여 국소 패턴을 찾는다. 이처럼 공간적으로 가중치를 공유하는 것이 합성곱층의 핵심이다.

가중치 공유 덕분에 각 위치를 별도 가중치로 연결하는 층보다 파라미터를 줄일 수 있다. stride=1이고 경계의 영향을 제외하는 등 적절한 조건에서는 입력을 옮기면 반응 위치도 따라 옮겨지는 이동 등변성이 나타난다. 임의의 패딩·stride·풀링까지 포함한 전체 CNN이 모든 이동에 정확히 같은 방식으로 반응한다고 일반화하지 않는다. 풀링이나 전체 위치의 집계는 위치 변화의 영향을 덜 받는 특징을 만드는 데 도움이 될 수 있다.

19.3 출력 크기 공식

길이 7에서 폭 3의 창을 stride=2로 움직이면 시작 위치는 0·2·4 세 개다. 6에서 시작하면 창이 입력을 넘어가므로 세지 않는다. 출력 크기는 창을 온전히 놓을 수 있는 시작 위치의 개수다. 패딩은 양끝에 칸을 더하고, dilation은 커널 원소 사이를 벌려 창이 차지하는 전체 폭을 바꾼다.

각 공간 축의 출력 크기는 다음과 같이 계산한다.

out = floor((in + 2P - D(K-1) - 1)/S + 1)

  • 입력 크기 in
  • 커널 크기 K
  • 패딩 폭 P
  • 이동 간격 S
  • 팽창 간격 D

K=7,S=1,D=1에서 입력 크기를 유지하려면 P=3이다.

실제 창의 폭은 D(K−1)+1이다. 패딩한 길이 in+2P에서 이 폭을 빼면 마지막 시작 위치까지 이동할 수 있는 길이가 된다. 이를 S로 나누고 소수 부분을 버린 뒤, 시작 위치 0 한 개를 포함해 +1 한다. 그래서 floor가 필요하다. 예를 들어 in=8,K=3,S=2,P=0,D=1이면 floor(5/2)+1=3으로, 나누어떨어지지 않아도 가능한 세 창을 계산한다. PyTorch의 일반 합성곱은 이 바닥값 규칙을 사용한다.

19.4 파라미터 수

출력 채널 하나를 만드는 필터는 기본 groups=1에서 입력 채널 전체를 본다. RGB의 3×3 영역이면 가중치 3×3×3개가 필요하고 출력 채널마다 다른 가중치 묶음을 학습한다. 공간 위치마다 새 가중치를 만들지는 않는다.

Conv2d의 파라미터 수:

out_channels × (in_channels/groups × K_h × K_w) + out_channels(bias).

Conv2d(3,64,7,bias=True)는 64×(3×7×7)+64 = 9472개다. 이미지 높이·너비와 파라미터 수는 무관하다.

필터 하나는 147개 가중치와 편향 하나를 가지며 그런 필터가 64개다. groups는 채널을 나누어 연결할 때의 묶음 수다. 각 출력 필터가 보는 입력 채널 수가 in_channels/groups로 줄고, 입력·출력 채널은 그룹으로 나눌 수 있어야 한다. 높이와 너비는 출력 활성값의 수와 연산량을 바꾸지만 필터 가중치의 개수는 바꾸지 않는다.

19.5 채널의 의미

RGB 이미지의 한 픽셀은 R·G·B 숫자 세 개를 가진다. HWC는 ‘몇 번째 행, 몇 번째 열, 어느 색인가’ 순서이고 CHW는 색상별 평면을 먼저 고른다. 축을 옮기는 것은 색 값을 바꾸는 연산이 아니다. 모델이 기대하는 위치 순서로 주소를 바꾸는 일이다.

첫 층의 입력 채널 수는 RGB 이미지에서 3, 흑백 이미지에서 1, 센서 Conv1d에서 특성 수 F다. 출력 채널 수는 학습하는 필터 수다. 이미지를 NumPy의 HWC 순서에서 PyTorch의 CHW 순서로 바꾼다.

PYTHON 예시
img = np.asarray(pil_img, dtype=np.float32) / 255.0  # [H,W,C]
if img.ndim == 2:
    img = img[..., None]
x = torch.from_numpy(img).permute(2, 0, 1)          # [C,H,W]

8비트 RGB 또는 흑백 이미지를 전제하면 255로 나누어 픽셀 범위를 0부터 1로 바꾼다. 흑백의 [H,W]에는 길이 1인 채널 축을 추가하고, permute가 마지막 채널 축을 앞으로 옮긴다. 배치까지 있으면 [B,H,W,C]→[B,C,H,W]이므로 permute(0,3,1,2)다. 서로 다른 픽셀에 다른 색을 붙이지 않도록 reshape로 축 교환을 대신하지 않는다. 16비트·float 이미지의 값 범위나 팔레트·알파 채널은 먼저 확인하고 필요한 모드로 변환한다.

19.6 풀링

작은 영역 [[1,3],[2,4]]를 숫자 하나로 줄일 때 최대 반응만 남기면 4, 평균을 남기면 2.5다. 두 계산 모두 원소 네 개를 하나로 요약하지만 어떤 정보를 보존하는지가 다르다. 풀링은 이 계산 규칙을 이동하며 적용한다.

  • MaxPool: 국소 영역에서 가장 큰 반응값을 선택한다.
  • AveragePool: 국소 영역의 평균값을 구한다.
  • AdaptiveAvgPool2d((1,1)): 입력의 높이·너비와 관계없이 채널마다 값 하나를 만들어 분류 헤드의 입력 차원을 고정한다.

풀링에는 학습 파라미터가 없다. 이동 간격을 크게 한 합성곱으로 크기를 줄일 수도 있다.

AdaptiveAvgPool2d((1,1))은 채널마다 공간 평균 하나를 남긴다. [B,128,16,16]이든 [B,128,20,24]든 [B,128,1,1]이 되어 같은 Linear 헤드에 연결할 수 있다. 크기가 같아진다고 원래 이미지의 모든 위치 정보가 보존되는 것은 아니다. 위치 자체가 정답인 문제에는 이런 전체 평균이 필요한 정보를 지울 수 있다.

19.7 수용 영역

두 번째 층의 출력 하나가 첫 번째 층의 세 위치를 보고, 그 각각이 원본의 세 위치를 본다면 실제로 원본의 몇 위치에 영향을 받을까? stride=1의 길이 3 합성곱을 두 번 쌓으면 첫 층의 창들이 겹쳐 원본 연속 5칸에 닿는다. 3×3을 두 번 쌓은 2차원에서도 이론적 범위는 5×5다. 층마다 본다고 원본에서 3×3=9칸의 길이를 보는 것은 아니다.

깊은 층의 출력값 하나가 원본에서 참조하는 영역이다. 3×3 합성곱을 여러 개 쌓으면 파라미터를 효율적으로 사용하면서 수용 영역을 넓히고 중간 비선형 변환도 늘릴 수 있다. 팽창 간격을 늘리면 커널 원소 사이가 벌어져 파라미터를 추가하지 않고도 수용 영역이 커진다.

stride가 있으면 다음 층의 이웃 위치 사이가 원본에서 더 멀어진다. 입력에서의 이웃 간격을 jump라고 할 때 새 수용 범위는 이전 범위+(커널의 실제 폭−1)×이전 jump, 새 jump는 이전 jump×stride다. 범위가 넓다는 사실과 그 안의 모든 입력이 같은 정도로 영향을 준다는 사실은 다르다.

19.8 작은 이미지 CNN

아래 모델은 [B,3,64,64] 이미지를 예로 들면 채널을 3→32→64→128로 늘리며, 두 번의 MaxPool로 공간을 64→32→16으로 줄인다. 그 뒤 각 채널의 공간 평균을 구해 표본당 128개 특징을 만들고, 마지막 Linear가 out_dim개의 점수로 바꾼다. 앞에서 계산한 층의 의미를 전체 경로로 연결해 보자.

PYTHON 예시
class ImageCNN(nn.Module):
    def __init__(self, in_channels, out_dim):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(in_channels, 32, kernel_size=3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(64, 128, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d((1, 1)),
        )
        self.head = nn.Linear(128, out_dim)

    def forward(self, x):
        x = self.features(x)       # [B,128,1,1]
        return self.head(x.flatten(1))

PYTHON 예시
m = ImageCNN(3, 5)
assert m(torch.zeros(2, 3, 64, 64)).shape == (2, 5)
assert m(torch.zeros(1, 3, 80, 96)).shape == (1, 5)

적응형 풀링 덕분에 높이·너비가 다른 입력도 같은 헤드로 처리할 수 있다. 다만 DataLoader의 기본 배치 묶기(collate)를 사용하려면 한 배치 안의 높이·너비가 같아야 하므로 크기 조절이나 패딩이 필요하다.

self.features는 특징 추출, self.head는 과제별 출력 부분이다. Conv의 padding=1은 kernel=3·stride=1에서 공간 크기를 유지한다. BatchNorm·ReLU는 shape를 그대로 두고, MaxPool2d(2)가 공간을 절반으로 줄인다. 마지막 flatten(1)은 [B,128,1,1]에서 B를 보존해 [B,128]로 만든다. 두 dummy test는 서로 다른 배치를 따로 넣는 검사이지 크기가 다른 이미지들을 하나의 배치로 바로 쌓는 예가 아니다.

0으로 채운 예제 입력은 형태 검사이며 성능 검사가 아니다.

19.9 PIL로 이미지 자르기

PIL의 자르기 영역(crop box)은 (left, upper, right, lower)이며 오른쪽·아래쪽 끝은 포함하지 않는다. 결과의 너비는 right-left, 높이는 lower-upper다.

좌표는 왼쪽 위를 기준으로 가로 x가 먼저, 세로 y가 다음이다. box=(1,2,4,6)이면 x 위치 1·2·3 세 열과 y 위치 2·3·4·5 네 행을 남기므로 너비 3·높이 4다. NumPy의 배열 shape는 보통 높이·너비 순서여서 [4,3,C]가 된다. 좌표의 x/y 순서와 배열의 행/열 순서를 구분해야 한다.

PYTHON 예시
from PIL import Image

def crop_to_array(image, box):
    if not isinstance(image, Image.Image):
        raise TypeError("PIL Image가 필요합니다")
    left, upper, right, lower = box
    if right <= left or lower <= upper:
        raise ValueError("유효하지 않은 crop box")
    return np.asarray(image.crop(box))

함수는 PIL 객체인지와 양수 크기의 영역인지 검사한 뒤 자르고 배열로 반환한다. 원본 image 자체를 덮어쓰지 않지만 이미지 바깥 좌표를 금지하는 검사는 없다. 경계 밖 영역의 처리를 문제에서 엄격히 정했다면 그 조건을 추가해야 한다. 결과가 RGB인지 흑백인지에 따라 배열 차원도 다르므로 ‘항상 3차원’이라고 가정하지 않는다.

19.10 실습문제

  1. 입력 크기 32, K=3, P=1, S=2, D=1일 때 출력 크기는?
    풀이에 필요한 이론

    출력 크기 공식은 창을 몇 번 놓는지 세는 식이다

  2. Conv2d(16,32,3,padding=1,bias=False)의 파라미터 수는?
    풀이에 필요한 이론

    그룹 수·파라미터 수·활성값 수를 구분한다

  3. RGB [B,64,64,3] 텐서를 NCHW 순서로 바꾸는 코드는?
    풀이에 필요한 이론

    이미지 좌표와 텐서의 축을 놓치지 않는다

  4. 풀링이 파라미터 수를 늘리는가?
    풀이에 필요한 이론

    풀링과 수용 영역을 단계별로 계산한다

  5. PIL 영역 (10,20,50,70)을 잘라낸 결과의 너비와 높이는?
    풀이에 필요한 이론

    이미지 좌표와 텐서의 축을 놓치지 않는다

정답·해설 보기

  1. 먼저 무엇을 봐야 하나: 한 공간 축의 in·K·P·S·D를 각각 적는다.

    풀이: 커널 실제 폭은 1×(3−1)+1=3, 패딩한 길이는 34다. 시작 위치 수는 floor((34−3)/2)+1=15+1이다.

    정답: 16이다.

    왜: stride 2로 온전히 놓을 수 있는 창의 위치를 세기 때문이다.

    헷갈리기 쉬운 부분: 소수 출력 16.5를 반올림하거나 패딩을 한쪽에만 더하지 않는다.

    한 줄 기억: 패딩 길이에서 실제 창 폭을 빼고 이동 가능한 위치를 센다.

  2. 먼저 무엇을 봐야 하나: 입력 16채널·출력 32채널·3×3·기본 groups=1·bias=False다.

    풀이: 출력 필터 하나는 16×3×3=144개 가중치를 갖고, 32개 필터가 있어 144×32다. 편향은 없다.

    정답: 4608개다.

    왜: 모든 공간 위치가 필터 가중치를 공유하기 때문이다.

    헷갈리기 쉬운 부분: padding=1이나 이미지 넓이를 파라미터 수에 곱하지 않는다.

    한 줄 기억: 필터당 가중치×출력 필터 수, 편향은 조건대로 더한다.

  3. 먼저 무엇을 봐야 하나: 현재 축 0·1·2·3이 B·H·W·C다.

    풀이: B는 0번을 유지하고 C인 3번을 두 번째로 옮긴 뒤 H·W인 1·2번을 놓는다.

    정답: x = x.permute(0,3,1,2)다.

    왜: 값의 의미를 보존하며 채널 축의 위치만 옮겨야 하기 때문이다.

    헷갈리기 쉬운 부분: reshape로 같은 숫자 크기만 맞추면 픽셀과 색의 대응이 달라질 수 있다.

    한 줄 기억: shape만 같게 하지 말고 각 축의 이름을 따라 옮긴다.

  4. 먼저 무엇을 봐야 하나: 묻는 것은 출력 원소 수가 아니라 학습할 숫자의 수다.

    풀이: 최대·평균은 주어진 입력에서 정해진 규칙으로 계산한다. 최적화로 바꿀 필터나 편향이 없다.

    정답: 일반적인 최대·평균·적응형 풀링에는 학습 파라미터가 없다.

    왜: 배울 가중치 없이 요약하는 연산이기 때문이다.

    헷갈리기 쉬운 부분: stride 합성곱으로 크기를 줄이는 경우에는 필터 가중치가 있다.

    한 줄 기억: 크기를 줄이는 모든 층이 무파라미터인 것은 아니다.

  5. 먼저 무엇을 봐야 하나: 오른쪽·아래쪽 끝은 포함하지 않는 좌표다.

    풀이: 가로는 50−10=40, 세로는 70−20=50이다. 끝 좌표를 한 칸 더 세지 않는다.

    정답: 너비 40, 높이 50이다.

    왜: 반열린 구간의 길이는 끝−시작이기 때문이다.

    헷갈리기 쉬운 부분: RGB 배열의 shape는 (50,40,3)처럼 높이가 먼저다.

    한 줄 기억: crop 좌표는 x/y, 배열 shape는 행/열 순서를 확인한다.

19.11 완료 기준

커널 시작 위치를 직접 나열해 공식의 결과와 맞추고, 입력→각 층→최종 출력의 shape를 한 줄씩 적어 보자. 위치마다 같은 필터를 쓰는 이유는 Stanford CS231n 합성곱 강의의 국소 연결·가중치 공유 설명과 함께 볼 수 있다. 라이브러리의 stride·floor 동작은 이 교재의 PyTorch 정의로 구분한다.

스스로 확인하기

  1. 입력 10, 커널 크기 3, 스트라이드 2, 패딩 0, 팽창 간격 1인 한 축의 출력 길이는 얼마인가?
    풀이에 필요한 이론

    출력 크기 공식은 창을 몇 번 놓는지 세는 식이다

  2. Conv2d(2,5,3,bias=True)의 파라미터 수는? groups=1이다.
    풀이에 필요한 이론

    그룹 수·파라미터 수·활성값 수를 구분한다

  3. [B,8,4,4]에 AdaptiveAvgPool2d(1)을 적용하고 배치 축을 보존해 펼치면 형태는?
    풀이에 필요한 이론

    풀링과 수용 영역을 단계별로 계산한다

스스로 푼 뒤 정답과 이유 펼치기

  1. 먼저 볼 조건: 한 축의 길이 10, 커널 3, stride 2, padding 0, dilation 1을 표시한다.

    • 단계 풀이: 창 시작점은 0·2·4·6까지 가능하다. 시작점 6은 6·7·8을 읽는다. 다음 8은 8·9·10이어서 마지막 10이 범위를 벗어난다.
    • 정답: floor((10−3)/2+1)=4다. 마지막 창이 입력을 벗어나면 포함하지 않기 때문에 소수 부분을 버린다.
    • 왜: 완전한 창을 놓을 수 있는 위치 수가 출력 길이이기 때문이다.
    • 헷갈리기 쉬운 부분: 10÷2=5로 단순히 절반을 취하면 창 폭과 경계를 놓친다.
    • 한 줄 기억: 출력 크기는 유효한 창 시작점을 센다.

  2. 먼저 볼 조건: 입력 채널 2, 출력 채널 5, 3×3 창, 편향, groups=1을 확인한다.

    • 단계 풀이: 필터 하나는 두 입력 채널을 모두 읽으므로 2×3×3=18계수다. 다섯 필터가 90계수를 가지고 편향 다섯 개를 더한다.
    • 정답: 5×(2×3×3)+5=95개다. 출력 채널 다섯 개 각각이 입력 두 채널의 3×3 가중치와 편향 하나를 갖는다.
    • 왜: 출력 채널마다 별도의 필터와 편향을 학습한다.
    • 헷갈리기 쉬운 부분: 사진의 H·W나 창을 옮긴 횟수를 파라미터 수에 곱하지 않는다.
    • 한 줄 기억: 필터당 입력 채널 전체를 세고 출력 채널 수를 곱한다.

  3. 먼저 볼 조건: 풀링 목표가 1×1이고 배치 축을 보존한다는 조건을 확인한다.

    • 단계 풀이: 각 채널의 4×4 공간을 평균 하나로 줄여 [B,8,1,1]을 얻는다. 배치 뒤 축만 펼쳐 표본당 여덟 값을 만든다.
    • 정답: [B,8]이다. 각 채널의 공간을 값 하나로 요약하고 1×1 공간축만 펼친다. B까지 합치지 않는다.
    • 왜: 공간만 요약하고 여덟 채널의 종류는 유지하기 때문이다.
    • 헷갈리기 쉬운 부분: B까지 펼치거나 전체 채널을 하나의 평균으로 섞지 않는다.
    • 한 줄 기억: 적응형 1×1 풀링은 채널마다 값 하나다.
