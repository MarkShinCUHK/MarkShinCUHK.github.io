Jupyter를 처음 쓰거나, 실행이 안 된다면

HTML은 더블클릭해서 읽는 안내입니다. ipynb는 Jupyter에서 코드 셀을 실행하는 파일이고, py는 Python 소스 파일입니다. 웹사이트 자체가 Python을 실행해 주는 것은 아닙니다.

이미 Jupyter를 쓰고 있다면 압축을 푼 폴더에서 03-basics-practice.ipynb를 엽니다. 셀은 위에서부터 Shift+Enter로 실행하세요. 실행 중에는 셀 옆에 [*]가 보입니다. 위쪽 셀에서 오류가 나면 멈추고 그 오류부터 해결합니다.

설치부터 필요하다면 Python 실행 환경 기초를 먼저 보세요. 패키지 설치에는 인터넷이 필요하며, 설치를 마친 뒤에는 포함된 연습 자료로 오프라인 실습할 수 있습니다.

설치법은 00-START.html, 패키지 목록은 support/requirements.txt에 있습니다. 기초 노트북은 실습 데이터를 셀에서 만들므로 별도 CSV를 찾지 않아도 됩니다.

ModuleNotFoundError는 패키지가 없거나 다른 Python 커널을 골랐을 수 있다는 뜻입니다. FileNotFoundError는 파일 경로, FileExistsError는 이미 같은 이름으로 저장한 결과가 있는지부터 확인합니다.
