받은 다음, 이 순서대로 하세요

  1. ZIP을 풀고 manual.html을 열어요

    처음에는 P01 한 문제만 읽으세요. 15문제를 한꺼번에 풀지 않습니다.

  2. 00-start.ipynb로 실행 환경을 확인해요

    이 노트북은 검사 명령을 실행하는 도구입니다. 정답 함수를 작성하는 곳은 다음 단계의 .py 파일입니다.

  3. process_starter.py의 scale_sensor_columns를 고쳐요

    P01에 해당하는 TODO만 작성하고 파일을 저장합니다. 다른 문제의 미완성 코드는 아직 건드리지 않습니다.

  4. P01 검사 명령을 실행해요

    처음의 NotImplementedError는 아직 답을 쓰지 않았다는 뜻입니다. 작성 후 검사하고, 막히면 P01의 힌트 → 수정 매뉴얼 → 해설 순서로 확인합니다.

  5. 모델 학습 문제는 problem_starter.py에서 풀어요

    Process와 다른 파일입니다. B01부터 한 분기씩 작성합니다. 데이터 형식 NPZ와 검사 명령은 이 연습팩용이며 실제 시험 제출 형식과 다를 수 있습니다.

첫 문제 P01: 고칠 곳은 한 군데

process_starter.py의 scale_sensor_columns를 작성하고 저장한 뒤 아래 명령을 실행합니다. Jupyter 셀에서는 현재 커널의 Python을 사용합니다.

import sys
import subprocess
subprocess.run([sys.executable, "check_process.py", "--case", "P01",
                "--file", "process_starter.py"], check=True)

Jupyter를 처음 쓰거나, 실행이 안 된다면

HTML은 더블클릭해서 읽는 안내입니다. ipynb는 Jupyter에서 코드 셀을 실행하는 파일이고, py는 Python 소스 파일입니다. 웹사이트 자체가 Python을 실행해 주는 것은 아닙니다.

이미 Jupyter를 쓰고 있다면 압축을 푼 폴더에서 00-start.ipynb를 엽니다. 셀은 위에서부터 Shift+Enter로 실행하세요. 실행 중에는 셀 옆에 [*]가 보입니다. 위쪽 셀에서 오류가 나면 멈추고 그 오류부터 해결합니다.

설치부터 필요하다면 Python 실행 환경 기초를 먼저 보세요. 패키지 설치에는 인터넷이 필요하며, 설치를 마친 뒤에는 포함된 연습 자료로 오프라인 실습할 수 있습니다.

실전팩의 requirements.txt와 hdat_templates.py는 practical-labs 폴더 바로 안에 있습니다. support 폴더를 찾지 마세요. data의 NPZ 파일은 CSV가 아니며, manual.html과 00-start.ipynb의 읽기·검사 셀을 따릅니다.

ModuleNotFoundError는 패키지가 없거나 다른 Python 커널을 골랐을 수 있다는 뜻입니다. FileNotFoundError는 파일 경로, FileExistsError는 이미 같은 이름으로 저장한 결과가 있는지부터 확인합니다.

정답을 쓰기 전 NotImplementedError가 날 수 있습니다. 이는 미완성 문제를 알리는 표시이며, 라이브러리 설치 오류와 다릅니다.
