# HDAT-DS Study Hub

HDAT-DS 2026 대비용 PyTorch 학습 허브의 공개 정적 배포 저장소입니다.

- 사이트: https://markshincuhk.github.io/hdat-ds-study-hub/
- 구성: 34강 강의, 필기·실기 연습, 오픈북 치트시트, 실행형 PyTorch 코드
- 배포: GitHub Pages (`main` 브랜치 루트)

이 자료는 개인 학습용 비공식 자료이며 현대자동차그룹 또는 현대엔지비의 공식 사이트가 아닙니다. 시험 당일 문제 지시와 공식 규정이 항상 우선합니다.

이 저장소에는 공개용으로 검수한 정적 산출물만 포함되어 있습니다.
