이번 점검에서 바꾼 것

  • 필기 3회차 해설에서 문장 속 숫자를 문항 번호로 잘못 읽던 생성 오류를 수정했습니다.
  • 다중 라벨 Macro-F1과 다중출력 분류 평균을 구분하고, 소수로 입력된 클래스 번호가 정수로 바뀌어 통과하거나 NaN 예측이 정상 라벨로 처리되는 오류를 막았습니다.
  • 배치가 비어 있거나 검증 데이터의 마지막 배치가 누락되면 오류를 알리도록 했습니다. 불완전한 검증 결과로 체크포인트를 선택하지 않게 하기 위한 검사입니다.
  • IQR 이상치 판정의 상·하한, LSTM의 세 게이트와 후보 셀 상태를 명확히 설명했습니다. CrossEntropyLoss에 클래스 번호를 넣는 경우와 확률 분포를 넣는 경우도 구분했습니다.
  • 읽기 설정, 모바일 검색 이름, 복사 실패 안내, 검색의 치트시트·실습·보충강의 범위를 보강했습니다.
  • 연습용 보조 함수를 불러오는 방법과 실제 시험 답안을 작성하는 방법을 구분했습니다. 시험에서는 지정된 작성영역·변수·저장 셀을 따라야 합니다.
