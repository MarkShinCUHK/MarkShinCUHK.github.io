Process · 쉬움 · 권장 8분. 표 전체를 바꾸지 않고 지정된 열만 정확하게 바꾸는 문제입니다.

문제와 입출력 조건

scale_sensor_columns(frame, columns)를 구현하세요. frame은 열 이름이 유일한 pandas DataFrame이고, columns는 중복 없는 열 이름 리스트입니다. 선택한 열은 수치형이며 NaN은 허용하지만 Inf는 입력으로 주어지지 않습니다. 선택한 각 열에서 결측값을 제외하고 최솟값·최댓값을 구해 (x-min)/(max-min)을 계산하세요.

상수 열의 유효값만 0.0으로 바꾸고, 전부 NaN인 열은 NaN을 유지합니다. 선택한 열의 결과 자료형은 float64입니다. 선택하지 않은 열의 값·자료형, 행·열 순서, 중복될 수 있는 인덱스는 유지합니다. 원본은 바꾸지 않고 새 DataFrame을 반환합니다. 빈 DataFrame과 빈 선택 목록도 허용합니다. 없는 열을 선택하면 KeyError, 선택 목록이 중복되면 ValueError를 발생시킵니다.

치트시트 수정 매뉴얼 펼치기
  1. Process 선택 열 가이드와 Min-Max 블록을 엽니다. process_starter.py의 scale_sensor_columns 안에 적용합니다.
  2. 전체 수치형 열을 자동 선택하지 말고 인수 columns만 반복합니다. 반환 직전 원본의 비선택 열을 새로 합치지 말고 복사본의 선택 열만 대입하세요.
  3. lo == hi를 사용합니다. np.isclose는 1e9와 1e9+0.25를 사실상 같은 수로 볼 수 있어 이 문제에서는 틀립니다.
  4. 상수 분기에서는 s.where(s.isna(), 0.0)로 NaN을 보존합니다. 그 외에는 표준식을 쓰면 전부 NaN인 열도 NaN으로 남습니다.
  5. 입출력 조건 순서대로 원본 유지·인덱스·자료형을 검사합니다.

해설과 재도전 펼치기

0으로 나누는 경우는 분기로 처리하되 결측값 처리 규칙과 혼동하지 않는 것이 핵심입니다. 훈련 데이터로 전처리를 학습해 재사용하는 Problem과 달리, 이 Process 문제에서는 전달받은 표 자체의 최솟값·최댓값으로 계산해야 합니다. 같은 Min-Max 변환이라도 문제에 따라 통계를 구할 데이터 범위가 달라집니다.

참고 구현은 solutions/process_solution.py의 _selected와 scale_sensor_columns입니다. 내 함수와 비교할 때 보조 함수의 입력 검사도 같이 읽으세요. 재도전: [5, NaN, 5], [NaN, NaN], [1e9, 1e9+.25], 빈 표를 직접 넣고 기대 출력을 먼저 종이에 쓰세요.

참고 코드 발췌 · 먼저 직접 구현한 뒤 비교

아래 함수·클래스는 process_starter.py의 같은 이름을 대체합니다. import는 starter의 것을 유지하세요.

PYTHON · 필요한 변수와 실행 위치 확인
def _selected(frame, columns):
    if not isinstance(frame, pd.DataFrame):
        raise TypeError("DataFrame 필요")
    if not frame.columns.is_unique or len(set(columns)) != len(columns):
        raise ValueError("열 이름은 중복될 수 없습니다")
    for col in columns:
        if col not in frame:
            raise KeyError(col)
        if not pd.api.types.is_numeric_dtype(frame[col]):
            raise TypeError("선택 열은 수치형이어야 합니다")
        if np.isinf(frame[col].to_numpy(dtype=float)).any():
            raise ValueError("Inf 입력은 허용하지 않습니다")
    return frame.copy(deep=True)


def scale_sensor_columns(frame, columns):
    out = _selected(frame, columns)
    for col in columns:
        s = frame[col].astype("float64")
        lo, hi = s.min(), s.max()
        out[col] = s.where(s.isna(), 0.0) if hi == lo else (s - lo) / (hi - lo)
    return out
