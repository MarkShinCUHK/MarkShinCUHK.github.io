Process · 보통 · 권장 10분. PyTorch 손실함수를 호출하지 않고 NumPy로 수식을 구현합니다.

문제와 입출력 조건

mean_logit_loss(logits, labels)를 구현하세요. logits는 유한한 실수 (N,C) 배열이며 N≥1, C≥1입니다. labels는 정수형 (N,) 배열이고 값의 범위는 0부터 C-1입니다. 각 행에서 소프트맥스의 정답 클래스 확률에 음의 로그를 취한 뒤 평균하여 Python float 하나를 반환합니다. 내부 연산은 float64로 하고 입력은 바꾸지 않습니다.

형태가 잘못되었거나 입력이 비어 있으면 ValueError를 발생시킵니다. 실수형·bool형 labels, 범위 밖 라벨, NaN/Inf가 있는 logits도 ValueError입니다. 특히 (N,1) 형태의 labels를 자동으로 펼쳐 받아들이지 않습니다.

입출력 명세 · 실행 코드 아님
logits=[[0,0],[log(3),0]], labels=[0,1]
정답=(log(2)+log(4))/2 ≈ 1.03972077
logits가 모두 1000인 3클래스 → log(3), overflow 없어야 함
C=1, labels가 모두 0 → 0.0
힌트 펼치기

로짓에 같은 수를 더하거나 빼도 소프트맥스 확률은 같습니다. 각 행의 최댓값을 빼고 지수를 계산하세요. 확률을 만든 뒤 log(0)을 피하려고 임의의 작은 값 엡실론(epsilon)을 더하기보다 로짓에서 직접 로그-합-지수(log-sum-exp)를 계산하는 편이 정확합니다.

치트시트 수정 매뉴얼 펼치기
  1. NumPy 수치 함수를 엽니다. 평균 MSE 예시라면 반복 뼈대만 참고하고 계산식은 반드시 바꿉니다.
  2. 입력 조건을 먼저 확인합니다. labels를 무조건 astype(int) 하면 0.9 같은 잘못된 입력도 오류 없이 통과하므로 먼저 정수 자료형인지 검사합니다.
  3. z = x.astype(np.float64) - x.max(axis=1, keepdims=True)를 만듭니다. keepdims가 있어야 행별 최댓값이 같은 행에 적용됩니다.
  4. np.log(np.exp(z).sum(axis=1)) - z[np.arange(N), y]가 표본별 손실입니다. 평균을 구해 float(...)로 반환합니다.
  5. 형태·손실함수 표로 실제 모델 학습에서는 CrossEntropyLoss에 소프트맥스를 적용하기 전 로짓을 입력하는 이유까지 연결하세요.

해설과 재도전 펼치기

최댓값을 빼면 지수함수의 입력 최댓값이 0이므로 큰 양수의 지수 계산에서 발생하는 오버플로(overflow)를 막습니다. 로그-합-지수에서 정답 로짓을 빼므로 공통으로 뺀 값도 상쇄됩니다. 반면 확률에 엡실론을 더하면 원래 수식의 값이 달라질 수 있습니다.

참고 함수 mean_logit_loss와 비교하고 로짓에 10000을 더한 결과가 같은지 검사하세요. 재도전: labels의 형태가 (2,1)인 경우, -1인 경우, C=1인 경우를 직접 실행하고 명세에 맞는 성공/실패를 예측하세요.

참고 코드 발췌 · 먼저 직접 구현한 뒤 비교

아래 함수·클래스는 process_starter.py의 같은 이름을 대체합니다. import는 starter의 것을 유지하세요.

PYTHON · 필요한 변수와 실행 위치 확인
def mean_logit_loss(logits, labels):
    x, y = np.asarray(logits), np.asarray(labels)
    if x.ndim != 2 or x.shape[0] < 1 or x.shape[1] < 1:
        raise ValueError("logits는 비어 있지 않은 (N,C)")
    if y.shape != (x.shape[0],) or not np.issubdtype(y.dtype, np.integer):
        raise ValueError("labels는 정수 (N,)")
    if not np.issubdtype(x.dtype, np.number) or np.iscomplexobj(x) or not np.isfinite(x).all():
        raise ValueError("유한한 실수 logits 필요")
    if np.any(y < 0) or np.any(y >= x.shape[1]):
        raise ValueError("label 범위 오류")
    z = x.astype(np.float64) - x.max(axis=1, keepdims=True)
    return float(np.mean(np.log(np.exp(z).sum(axis=1)) - z[np.arange(len(y)), y]))
