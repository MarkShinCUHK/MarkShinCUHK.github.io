문제와 입출력 조건

add_prior_average(frame, group_col, time_col, value_col, window=2)를 구현하세요. 그룹 열은 결측 없는 문자열, 시간 열은 결측 없는 정수이고, 값 열은 수치형이며 NaN을 허용합니다. 열 이름은 유일하고 원본 인덱스는 중복될 수 있습니다.

그룹별로 시간 오름차순으로 정렬하되, 시간이 같으면 원래 행 위치가 앞선 것을 먼저 둡니다. 각 행에서 현재 행을 제외한 직전 window개의 관측 행의 평균을 계산합니다. NaN은 그 범위의 평균 계산에서 제외하며, 사용할 유효값이 없으면 NaN을 반환합니다. 유효값 window개를 찾을 때까지 더 과거로 이동하라는 뜻은 아닙니다.

원본은 변경하지 않습니다. 기존 값·자료형·인덱스·순서를 모두 유지한 표를 반환하고, 마지막에 float64형 <value_col>_prior_mean 열을 추가합니다. 그 열이 이미 있으면 ValueError, 인수로 지정한 열이 없으면 KeyError를 발생시킵니다. window는 bool이 아닌 양의 정수여야 하며, 그렇지 않으면 ValueError를 발생시킵니다. 빈 표도 허용합니다.

힌트 펼치기

그룹별로 shift(1)을 먼저 적용한 뒤 rolling(window, min_periods=1).mean()을 계산합니다. 원본 인덱스가 중복되므로 인덱스로 원래 순서를 복원하려 하지 말고, 0부터 시작하는 행 위치를 별도로 기록하세요.

치트시트 수정 매뉴얼 펼치기
  1. 그룹별 시차·이동 통계을 엽니다. group_col, time_col, value_col은 문자열 인수로 받고 실제 열 이름을 하드코딩하지 마세요.
  2. 임시 표에 그룹·시간·값·행 위치만 담습니다. 원본 표에 _row라는 임시 열을 직접 만들면 기존 동명 열을 덮을 수 있습니다.
  3. 그룹, 시간, 행 위치의 세 기준으로 정렬합니다. 이어서 groupby(...).transform(...) 안에서 시차 이동과 이동 평균 계산을 함께 수행합니다.
  4. 결과를 길이 N의 NaN 배열에 result[정렬된 원래위치] = 계산값으로 배치합니다. 마지막에 원본 복사본의 새 열로 넣습니다.
  5. A그룹의 첫 행에 B그룹의 값이 섞이지 않는지, 현재 행을 99999로 바꿔도 그 행의 과거 평균은 그대로인지 검사합니다.

해설과 재도전 펼치기

현재값을 제외하지 않으면 ‘현재값으로 현재를 예측’하는 누수가 생깁니다. 그룹 구분 없이 이동 평균을 계산하면 다른 설비의 기록이 섞입니다. 정렬 결과 그대로 반환하면 값 계산이 맞아도 예측값과 제출 행의 대응이 틀립니다.

참고 함수 add_prior_average는 임시 표를 따로 만들어 원본과 충돌을 피합니다. 재도전: 동일 그룹 값 [10, NaN, 30, 40], 순서 [1,1,2,3], window=2의 결과는 [NaN,10,10,30]입니다. 마지막 평균이 20이 아닌 이유를 설명하세요. window=1, 중복 인덱스, _row 원본 열도 검사합니다.

def _selected(frame, columns):
    if not isinstance(frame, pd.DataFrame):
        raise TypeError("DataFrame 필요")
    if not frame.columns.is_unique or len(set(columns)) != len(columns):
        raise ValueError("열 이름은 중복될 수 없습니다")
    for col in columns:
        if col not in frame:
            raise KeyError(col)
        if not pd.api.types.is_numeric_dtype(frame[col]):
            raise TypeError("선택 열은 수치형이어야 합니다")
        if np.isinf(frame[col].to_numpy(dtype=float)).any():
            raise ValueError("Inf 입력은 허용하지 않습니다")
    return frame.copy(deep=True)


def add_prior_average(frame, group_col, time_col, value_col, window=2):
    if isinstance(window, (bool, np.bool_)) or not isinstance(window, (int, np.integer)) or window < 1:
        raise ValueError("window는 양의 정수")
    out = _selected(frame, [value_col])
    name = f"{value_col}_prior_mean"
    if name in frame:
        raise ValueError("출력 열이 이미 존재합니다")
    for col in (group_col, time_col):
        if col not in frame:
            raise KeyError(col)
    if frame[group_col].isna().any() or frame[time_col].isna().any():
        raise ValueError("group/time 결측 불가")
    # 원본 index는 중복 가능. 위치 전용 임시 표로 안전하게 계산한다.
    work = pd.DataFrame({"g": frame[group_col].to_numpy(), "t": frame[time_col].to_numpy(),
        "v": frame[value_col].to_numpy(dtype=float), "pos": np.arange(len(frame))})
    work = work.sort_values(["g", "t", "pos"], kind="stable")
    value = work.groupby("g", sort=False)["v"].transform(lambda s: s.shift(1).rolling(window, min_periods=1).mean())
    result = np.full(len(frame), np.nan, dtype=np.float64)
    result[work["pos"].to_numpy()] = value.to_numpy()
    out[name] = result
    return out
