치트시트를 코드에 연결하는 공통 순서

  1. 문제 유형 결정표를 열고 문제의 입력 형태를 찾습니다. 표면적인 ‘자동차’라는 소재보다 표·이미지·시계열인지가 중요합니다.
  2. 유형별 가이드에서 해당 유형을 엽니다. 문제별 매뉴얼에는 정확한 번호와 함수명이 적혀 있습니다.
  3. Process는 비슷한 함수를 가져오되 이 문제의 명세가 우선입니다. 예를 들어 이미지의 중앙을 자르는 것과 왼쪽 위를 자르는 것은 같은 답이 아닙니다.
  4. Problem은 import hdat_templates as h 후 전처리, 모델, 학습 루프, 제출 변환의 네 부분을 연결합니다. h.MLP를 복사할 필요 없이 h.MLP(입력열수, 출력개수)처럼 호출합니다.
  5. 아래 공통 실행 블록을 쓰려면 앞에서 Xtr, Xva, Xte, ytr, yva, model, task, score_fn, maximize를 모두 정의해야 합니다. 이 이름들은 자동으로 생기지 않습니다.

task는 손실함수와 정답 자료형을 정합니다. score_fn은 각 에포크(epoch)에서 어떤 모델을 남길지 결정합니다. 분류에서는 손실을 줄이면서 Macro-F1 또는 AUC가 가장 높은 모델을 고를 수 있습니다. 학습에 쓰는 손실과 모델 선택 지표는 목적이 다릅니다. 학습 반복문은 가장 좋은 에포크의 가중치를 돌려주므로 마지막 에포크의 모델로 임의 교체하지 마세요.

매번 ‘첫 유효 출력까지 걸린 시간 / 펼친 힌트 수 / 잘못 구현한 조건 / 검증 지표 / 다시 시도할 한 가지’를 적으세요. 합성 데이터는 작고 비교적 단순합니다. 높은 점수를 받았더라도 실제 데이터의 잡음·불균형·자원 제한에 대비한 검증과 시간 관리까지 익혔다고 단정하지 마세요.
