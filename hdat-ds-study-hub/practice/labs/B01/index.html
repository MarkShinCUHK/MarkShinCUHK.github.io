문제와 입출력 조건

서로 독립인 합성 표본의 센서 특성 6개와 생산라인 범주로 품질 라벨 10/20/40을 예측하세요. data/B01.npz의 훈련 480행, 검증 120행, 테스트 97행은 이미 분리되어 있습니다. 각 X는 float32 (N,6)이며 NaN을 포함합니다. category_*는 (N,) 문자열이고, 테스트 데이터에는 훈련에 없던 범주 D가 포함됩니다. y_train/y_valid는 (N,) 정수입니다.

테스트 배열 순서대로 (97,) 형태의 원래 정수 라벨을 반환합니다. 클래스 인덱스 0/1/2나 (97,3) 확률은 제출 답이 아닙니다. 평가지표는 클래스 10/20/40을 모두 포함한 Macro-F1이며 클수록 좋습니다. 신경망은 PyTorch를 사용하세요.

힌트 펼치기

문제의 숫자 라벨이 10/20/40이라는 사실과 모델의 출력 노드가 3개라는 사실을 구분하세요. CrossEntropyLoss에 넣는 정답은 0/1/2여야 합니다. 테스트 예측 후 원래 라벨로 되돌립니다.
