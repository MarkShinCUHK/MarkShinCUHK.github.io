# 34강 문제·선행 이론 보강 기록

개정일: 2026-09-08. 이번 개정의 목적은 **본문에서 배우지 않은 지식을 문제에서 갑자기 요구하는 간격을 줄이는 것**이다. 기존 개념 그림, 실습문제, 별도 해설, 진도 기록과 주소를 유지했다.

## 읽는 순서

1. 그림과 쉬운 설명: 상황·용어·작은 숫자를 이해한다.
2. **필기 이론: 정의에서 풀이까지**: 정의, 기호, 성립 조건, 유도, 다른 숫자의 예제를 읽고 손으로 재현한다.
3. 수식·코드·실전 확장과 기존 실습: 앞에서 배운 원리를 적용한다.
4. 마지막 기초 확인문제: 설명 없이도 핵심을 말할 수 있는지 확인한다.

문제의 **풀이에 필요한 이론**을 열면 같은 강의의 해당 설명으로 돌아간다. 이론 절 끝에는 적용 문제로 돌아가는 링크가 있다. 정답과 이유는 별도의 접힌 해설에 남겨 두었다. 이 기능은 오프라인 통합 HTML에서도 동작한다.

## 대조 범위와 실제 보강

- 본과정 34강에 이론 186절을 추가했다. 공식만 나열하지 않고, 식이 나오는 이유와 조건을 설명했다.
- 기존 문제·소문항 371개를 대조했다: 기존 심화 문제·모의·회고 항목 258개와 그림 교재 확인문제 113개다. 통합 과제의 전체 요구와 소과제도 각각 포함하므로 서로 독립적인 공식 시험문제 371개라는 뜻은 아니다.
- 모든 항목을 해당 강의의 선행 이론에 연결했다. 문항 목록과 연결은 `question-prerequisites.json`에서 확인할 수 있다.
- 필기 모의 3회 60문항은 31강의 12개 이론 절에서 다시 준비한다. 오답 번호 암기 대신 조건·계산·모델 비교를 설명한다.
- 서로 다른 38개 문항의 39곳에서 누락 조건과 모호한 표현을 명확히 했다. 17곳의 해설·도입·코드 수정 제안도 반영하고 관련 본문과 구현 검사를 정리했다. 문제를 삭제하거나 난이도를 낮추어 맞춘 것이 아니다.

대표적인 수정은 다음과 같다.

| 주제 | 이전의 간격 | 보강 내용 |
|---|---|---|
| 공분산·PCA | rank와 고유값을 설명 없이 계산 | 중심화 → 공분산 각 칸 → 고유벡터 → 투영 좌표·분산을 손계산 |
| 미분·규제 | optimizer 이름과 공식 위주 | 연쇄법칙, gradient 누적, L1의 0 해, 기본 SGD와 AdamW의 다른 조건 |
| 확률·정보이론 | Gaussian→MSE와 KL 판단의 근거 부족 | likelihood·로그부터 유도, 고정 분산 전제, 비대칭·삼각부등식 수치 반례 |
| 평가지표 | AUC에 확률이 반드시 필요하다는 문항 | ranking score·확률·calibration·AP의 목적과 입력을 구분 |
| PyTorch 계약 | one-hot·freeze·mask의 단정적 표현 | CE의 두 target 경로, 남아 있는 gradient, API별 bool mask 차이 |
| 시계열 | target 시점과 예측 원점 혼동 | 첫/마지막 window, label이 알려지는 시점, horizon gap을 직접 계산 |
| VAE | 복원항·KL 공식만 암기 | Bayes 규칙에서 ELBO 항등식, log-likelihood 하한, 재매개화와 KL 수치 |
| Process 모의 | 분위수·rolling·반환값·잘못된 파일명 | 보간식, `min_periods=1`, 명시적 입력·출력·예외 계약, 실제 파일명 |

32강 CE 모범답안은 큰 공통 logit을 더했다가 빼며 잃는 정밀도를 피하도록 바꾸었다. split의 차원 검사, crop 정수 검사, convolution의 bool 검사도 문제와 맞췄다. 전체 NaN 열은 통계를 계산하지 않고 보존한다.

## 확인한 것

- 수학·데이터, 모델·학습, 응용·모의 세 구간으로 나누어 원문 문제와 해설을 대조했다. 별도의 교차 검토에서 ELBO의 로그 표현, rolling 기본 옵션, scale의 양수 조건, SGD와 gradient 부호 설명의 전제를 수정했다.
- 웹 회귀 검사 45개 통과: 34강 표시, 기존 코드·그림·주소 유지, 371개 연결의 실제 도착점, 모든 선행 이론이 문제보다 먼저 표시되는 순서, 검색, 오프라인 HTML의 중복 ID 등을 검사했다.
- GitHub Pages 정적 출력 검사 7개 통과: 34강의 같은 학습 순서·371개 연결, 사이트 경로 접두사, 모든 내부 링크·검색 주소, 다운로드와 비공개 파일 제외를 확인했다.
- `tsc --noEmit` 통과.
- 기존 그림 교재의 독립 실행 예제 34개와 본과정 3강의 예제 9개·거절 조건 5개도 다시 실행해 통과했다.
- 독립 이론·API 검사 15개와 **실제로 게시하는 32강 모범답안** 검사 8개 통과. CE의 `1e18` 공통 logit, 잘못된 차원, 정수/boolean 경계, NaN rolling, B=1의 평가 출력을 포함했다.
- 수학 구간 독립 수치 검사 89개와 응용 구간 수치·shape 검사 54개를 별도로 통과했다. 모델 구간도 AUC·AP, BN, Conv/RNN 파라미터, CE gradient, freeze·mask API를 실행해 대조했다.
- 이론 원고의 고유 외부 링크 86개 접근 확인. 공식 API 문서, 원 논문, 대학 강의 노트를 사용하며 출처 링크는 해당 개념 옆에 있다.

실행 환경은 Python 3.9, NumPy 2.0.2, pandas 2.3.3, scikit-learn 1.5.2, PyTorch 2.8.0 CPU다. 설명에 연결한 PyTorch 2.7 문서와 로컬 실행 환경을 구분한다. 이 결과는 해당 회차 시험 서버·GPU 환경에서 실행했다는 뜻이 아니다.

## 한계

자동 연결 검사는 링크와 순서를 검증하며, 모든 사람이 본문만 읽고 독립적으로 풀 수 있음을 증명하지는 않는다. 이론 내용은 문항별 사람처럼 읽는 검토와 수치 검산으로 보강했다. 이해가 막히는 설명은 계속 개선할 대상이다.

이 사이트의 연습문제는 독자 학습 자료다. 미공개 기출 재현, 전체 출제 가능성의 소진, 합격 또는 시험장 개인 파일 사용 가능 여부를 보장하지 않는다. 시험 회차의 공식 범위·환경·문제 지시·감독관 안내를 우선한다.
