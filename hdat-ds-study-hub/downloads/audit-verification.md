## 실행 환경과 경고

실행 검사는 CPU, Python 3.9.6, NumPy 2.0.2, pandas 2.3.3, PyTorch 2.8.0, scikit-learn 1.5.2에서 수행했다. 공식 시험 안내 버전과 동일한 환경은 아니다. 실제 시험에서는 당일 제공 환경·작성영역·제출 셀이 우선한다.

기초 그래프 검사에서는 화면 없는 Agg backend 때문에 show 경고가 있었다. 고전 ML 일부 예제에서는 NumPy 행렬곱의 divide/overflow/invalid RuntimeWarning이 발생했다. 경고를 숨기지 않았으며 점수·출력은 유한하고 검사를 통과했다. 작은 유한 행렬의 matmul도 같은 경고를 내면서 별도 einsum 참조와 수치가 일치하는 것을 확인했지만, 환경 경고의 근본 원인을 확정한 것은 아니다. 경고가 나면 입력·중간값의 isfinite를 검사하고 패키지/BLAS 환경을 기록한다. 실제 NaN/Inf를 무시하라는 뜻은 아니다.

2 step denoising AE는 무처리 baseline보다 나빴다. 이는 짧은 학습의 연결 검사이며 성능 개선을 주장하지 않는다. 작은 합성 이미지/이상탐지 문제의 높은 점수도 시험 난도나 합격선을 뜻하지 않는다.

## 고친 결함

1. 문장 속 `20.`을 문항 번호로 잘못 분리하던 필기 해설 생성.
2. multilabel label-macro F1과 다중출력 class-macro 평균의 혼동, 단일 label 확률 shape 처리.
3. fractional class index의 조용한 long 변환 및 soft-target의 임의 flatten.
4. NaN/Inf raw logits가 정상 class label로 바뀌어 제출 검사를 통과하던 경로.
5. 빈 배치와 validation drop_last에 의한 일부 표본 누락.
6. IQR 상한 누락, LSTM gate/candidate 혼동, CE 기본/soft-target 경로 설명.
7. 브라우저 저장 실패가 강의 코드복사 초기화까지 중단하던 경로, 실패해도 복사됨 표시, 모바일 검색 이름 누락.

## 여전히 별도로 확인해야 하는 것

공식 notebook/시험 계정 실행, 시험 실제 채점·합격선·숨은 입력, 모든 강의 코드의 모든 가능한 데이터에 대한 증명, 모든 화면 크기·스크린리더 실사용, 원본 ZIP 무결성과 전체 그림 검수는 이번 검사 결과에 포함되지 않는다. 주제 대응은 확인했지만 모든 출제 경우·난도를 완전히 커버한다는 보장은 하지 않는다.
