# HDAT-DS 독립 연습팩

1. ZIP 압축을 풀고 manual.html을 여세요.
2. 이 폴더에서 00-start.ipynb를 열거나 터미널을 여세요.
3. python -m pip install -r requirements.txt
4. process_starter.py / problem_starter.py를 직접 수정하세요.
5. 검사 명령과 문제별 수정 순서는 manual.html에 있습니다.

공식 기출문제나 데이터를 복제하지 않고 자체 제작한 합성 문제 15개입니다. 모든 신경망은 PyTorch로 구현합니다.
참고 풀이와 테스트 정답은 solutions 폴더에 별도로 공개되어 있습니다. 학습 코드에서 읽지 마세요.
NPZ는 이 팩의 로컬 연습 형식이며 실제 시험 제출 형식이 아닙니다. 시험장 파일 반입과 외부 접속은 해당 회차 규정을 따르세요.
Python 3.10 이상을 권장하며 GPU는 없어도 됩니다. 패키지는 오프라인 실행 전에 설치하세요.
학습용 요구 버전과 실제 시험 버전은 다를 수 있습니다.
검증 기록: verification.md (배포 전 실행 검증 결과).
