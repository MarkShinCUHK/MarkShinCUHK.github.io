## 이번 개편에서 바꾼 부분

- 본과정 34강의 첫 설명과 작은 계산 예제, 코드의 역할 설명을 보강했습니다. 전문어의 뜻을 다시 짚고, 비슷한 개념은 같은 입력으로 비교합니다.
- 34강의 기초 확인문제 113개 해설을 조건 확인·단계 풀이·정답·이유·오해·한 줄 기억으로 확장했습니다.
- 우선 점검 대상으로 요청한 9강은 앞부분뿐 아니라 기존 이론, Pipeline 코드 주변 설명, 원래 실습 5문항의 해설까지 보강했습니다. 9강은 기초 확인 4문항을 합쳐 총 9문항을 앞선 설명과 대조했습니다.
- Python 입문 10강에는 각 도구를 배우는 이유와 값을 따라가는 예제를, 보충 4강에는 모델 결합·Seq2Seq·SVD·탐색 식을 읽기 위한 설명을 더했습니다.
- 기존 68개 개념 그림을 유지하고, 9강에 특성 설계의 흐름을 보여 주는 6단계 카드를 추가했습니다. 긴 본문은 목차의 ‘개념별로 찾아보기’로 나누어 읽을 수 있습니다.
- 기존 코드와 문제, 북마크, 문제에서 이론으로 돌아가는 연결은 유지했습니다. 학습·검증·예측을 혼동하지 않도록 새 설명에도 실제 사용 시점을 명시했습니다.

## 9강에서 빠뜨리지 않았는지 확인한 범위

| 기존 범위 | 보강한 연결 |
|---|---|
| 비율·차이·곱·로그·제곱·날짜·빈도 특성 | 같은 관측값이어도 입력 표현에 따라 모델이 표현할 수 있는 관계가 달라짐 |
| 필터·래퍼·내장형, RFE | 같은 열에서 선택 기준을 어디서 얻는지 비교 |
| L1과 선택 효과 | 계수 0의 의미 → 작은 목적함수 비교 → L1/L2 계수 관례와 유도 |
| PCA, 분산·공분산·설명분산비 | 대각선 위 세 점 → 축과 좌표 → 네 점의 압축과 정답 손실 |
| LDA, min(F,C−1) | 클래스 평균 사이의 차이 방향 → 차원 상한 → 실제 유효 차원의 한계 |
| Pipeline과 학습 데이터에서만 fit | 입력 표의 의미 → 단계별 역할 → 출력 모양 → 검증 변환 |
| lag·difference·rolling | t3까지 알고 t4를 맞히는 한 시점에서 각 값 직접 계산 |
| centered rolling·전체 집계·그룹 | 예측 순간에 사용할 수 없는 정보가 들어가는 경로 |
| FFT·이미지 특성·메모리·검증 | 기존 범위 유지, 시간·단위·관측 조건과 함께 판단 |

## 참고한 대학 자료는 어떻게 쓰나요?

Berkeley Data 8·Data 100, Stanford CS109·CS231n, MIT 18.650·6.S191, Cornell CS4780/5780, CMU 10-301/10-601의 관련 공개 노트·슬라이드를 참고했습니다. 모든 자료가 같은 난이도는 아닙니다. 입문·학부 중급·고급 학부·학부/대학원 합반 여부를 관련 링크 설명에 적었습니다.

대학 슬라이드의 그림·문구를 모아 붙이지 않고, 개념을 도입하는 순서와 작은 예제로 추론하는 방식을 참고해 한국어 설명을 새로 작성했습니다. 라이브러리 동작은 공식 API 설명과 실행 검산으로 별도 대조합니다. 외부 강의의 제출 규칙이나 과제 요구를 HDAT 규칙으로 간주하지 않습니다.

[자료실의 대학 공개강의](https://markshincuhk.github.io/hdat-ds-study-hub/resources/#sources-title) 또는 각 강의 끝의 ‘함께 읽을 대학 강의·슬라이드’에서 관련 항목만 선택해 읽으세요. 외부 원문을 모두 읽어야 이 교재의 문제를 풀 수 있다는 뜻은 아닙니다.

## 학습할 때 확인할 것

‘정의 문장을 읽어 봤다’와 ‘새 조건에 적용할 수 있다’는 다릅니다. 예제를 가리고 같은 계산을 해 보고, 숫자나 예측 시점 하나를 바꿨을 때 무엇이 달라지는지 설명해 보세요. 정답과 다르면 결과 숫자보다 어느 조건을 다르게 해석했는지부터 비교하세요.

코드 실행 검사와 링크 검사는 오류를 줄이는 수단이지 누구나 혼자 완전히 이해한다는 보증은 아닙니다. 시험 범위와 허용 자료는 해당 회차의 HDAT 공식 안내가 우선합니다.
