# 1~34강 전체 개편 안내 · 2026-09-08

## 이번에는 어느 부분을 바꿨나요?

9강만 보강한 것이 아닙니다. 본과정 **1~34강 전체의 원래 본문, 필기 이론 186절, 원래 실습·모의고사·통합 과제 258문항의 해설**을 보강했습니다. 앞서 보강한 그림 설명과 기초 확인 113문항도 유지합니다. 합계 371문항에는 같은 강의에서 먼저 배울 수 있는 이론으로 돌아가는 연결이 있습니다.

기존 수식·개념·코드·표·문제를 유지하면서 다음 내용을 더했습니다.

- 이 방법이 필요한 문제 상황과 이미 알아야 할 내용
- 작은 입력에서 계산을 한 단계씩 따라가는 예제
- 처음 나오는 용어와 기호가 실제로 가리키는 대상
- 식의 각 항과 코드의 각 단계가 맡는 역할
- 값·모양·단위·조건을 바꿨을 때 달라지는 결과
- 비슷한 개념의 차이, 적용할 수 없는 조건, 흔한 오해

긴 문단과 해설도 나누었습니다. 각 강의의 개념 그림 2개, 세부 목차, 접어 둔 해설, 기존 북마크와 진도 기능은 유지합니다.

## 어디서부터 공부하면 되나요?

**Python의 변수만 아는 수준이라면** [Python 기초 1강](https://markshincuhk.github.io/hdat-ds-study-hub/start/01/)부터 시작하세요. NumPy 배열과 pandas 표를 직접 읽고 고를 수 있으면 [본과정 1강](https://markshincuhk.github.io/hdat-ds-study-hub/learn/01/)으로 이어 갑니다. 전체 순서는 [34강 목차](https://markshincuhk.github.io/hdat-ds-study-hub/learn/)에서 확인할 수 있습니다.

한 강의를 한 번에 끝내려고 하지 않아도 됩니다. 다음 순서로 **한 개념씩** 공부하세요.

1. 그림과 첫 예제를 읽고 무엇을 해결하려는 방법인지 말해 봅니다.
2. 계산 결과를 가리고 입력 숫자부터 직접 계산합니다. X는 입력, y는 정답, ŷ는 예측이라는 역할부터 확인합니다.
3. 필기 이론에서 같은 계산을 기호로 어떻게 쓰는지 읽습니다. 기호를 한국어 문장으로 풀어 보세요.
4. 수식·코드·실전 확장에서 실제 구현의 입력·출력·중간 결과를 연결합니다.
5. 문제를 먼저 풀고 해설을 엽니다. 틀렸다면 결과 숫자보다 처음 다르게 해석한 조건을 찾습니다.
6. 숫자나 조건 하나를 바꿔 다시 설명합니다. 답을 외운 것과 원리를 이해한 것을 구별하기 위한 단계입니다.

필기 공부에서는 정의뿐 아니라 계산의 가정과 반례까지 확인하세요. 실기 공부에서는 그 원리를 입력 형태·자료형·행 순서·저장 파일의 조건에 연결하세요. 오픈북에서 코드를 빨리 찾는 연습은 기본 원리를 이해한 뒤에 합니다.

## 문제 해설은 어떻게 읽나요?

원래 실습문제와 기초 확인문제 모두 다음 여섯 부분으로 풀이를 확인할 수 있습니다.

1. **먼저 무엇을 봐야 하나:** 주어진 조건과 구해야 할 것을 구분합니다.
2. **풀이:** 계산·추론·코드 실행의 순서를 따라갑니다.
3. **정답:** 최종 숫자·형태·설명 또는 구현이 만족해야 하는 기준을 확인합니다.
4. **왜:** 풀이가 성립하는 원리를 연결합니다.
5. **헷갈리기 쉬운 부분:** 자주 하는 착각과 적용 조건을 확인합니다.
6. **한 줄 기억:** 비슷한 문제에서 다시 사용할 판단 기준을 남깁니다.

학습 결과에 따라 수치가 달라지는 모델링 과제에는 임의의 정확도를 정답으로 제시하지 않습니다. 대신 데이터 분할, 입력과 정답의 대응, 기준 모델과의 비교, 출력 파일 등의 확인 절차를 제시합니다. 구현 문제는 모범 코드뿐 아니라 경계조건과 실패했을 때 확인할 지점도 읽으세요.

## 대학 강의 자료는 어떻게 참고했나요?

관련 공개 대학 노트·슬라이드에서 문제를 도입하고 작은 예제로 추론하는 방식을 참고해 한국어 설명을 새로 작성했습니다. 그림이나 문구를 모아 붙인 교재는 아닙니다. Berkeley Data 8·Data 100, Stanford CS109·CS231n, MIT 18.650·6.S191, Cornell CS4780/5780, CMU 10-301/10-601 등의 자료는 각 강의와 자료실에 연결되어 있습니다. 입문·학부 중급·고급 학부·학부/대학원 합반은 난이도가 다르므로 링크 설명도 함께 확인하세요.

[자료실의 대학 공개강의](https://markshincuhk.github.io/hdat-ds-study-hub/resources/#sources-title) 또는 강의 끝의 ‘함께 읽을 대학 강의·슬라이드’에서 필요한 항목을 골라 읽으면 됩니다. 외부 원문을 전부 읽어야 교재 문제를 풀 수 있다는 뜻은 아닙니다. 라이브러리의 구체적인 동작은 공식 API 문서와 수치 검산으로 따로 확인합니다.

대학 강의의 과제 규칙을 HDAT 규칙으로 간주하지 않습니다. 이 교재는 개인 학습용 비공식 자료이며, 시험 범위·환경·허용 자료는 해당 회차의 공식 안내가 우선합니다.

## 무엇을 검증했으며, 무엇을 보장하지 않나요?

개편 전의 문제 문장·번호, 코드와 출력 블록, 표, 제목과 북마크를 대조하고, 문항과 선행 이론의 연결을 검사합니다. 새 손계산 예제와 기존 수치 예제는 독립적인 계산으로 검산하며, 웹 페이지와 다운로드 교재를 같은 원고에서 생성합니다.

이 검사는 누락과 오류를 줄이는 수단이지 모든 학습자가 혼자 완전히 이해하거나 합격한다는 보증은 아닙니다. 설명 없이 예제를 다시 풀 수 있는지, 조건을 바꿔도 적용할 수 있는지로 자신의 이해를 확인하세요. 합격을 보장하는 표현 대신, 실제로 설명하고 구현할 수 있는 범위를 늘리는 것을 목표로 합니다.
