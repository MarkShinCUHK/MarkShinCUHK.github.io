# HDAT-DS 2026 학습계획 — PyTorch로 준비하기

시험까지 남은 기간과 현재 실력에 맞춰 고르는 계획표다. 파이썬을 거의 처음 배운다면 **입문 10일과 본과정 21일을 합친 31일 일정**을 권장한다. 이미 Python·NumPy·pandas를 사용할 수 있다면 21일 본과정부터 시작한다. 학부 수준의 머신러닝·딥러닝을 배웠다면 9일 압축 일정을 참고한다. 마지막 3일 일정은 새 내용을 배우는 과정이 아니라 이미 공부한 내용을 점검하는 용도다.

> 시험 구성·실행 환경·금지행위는 2026 HDAT-DS 공식 매뉴얼과 해당 회차 안내에서 다시 확인한다. 아래 시간 배분과 준비 상태 기준은 개인 학습을 위한 제안이며 공식 합격선이나 채점 기준이 아니다.

## 매일 공부하는 순서

1. 전날 배운 내용을 보지 않고 10분 동안 설명한다.
2. 오늘 강의를 읽고 작은 예제의 출력값과 배열 크기를 예상한다.
3. Python 또는 PyTorch 코드를 직접 실행한 뒤 최소 한 곳을 바꾸어 결과를 비교한다.
4. 해설을 보지 않고 확인문제와 실습문제를 푼다.
5. 틀린 이유를 개념 / 배열 크기·자료형 / 누수·검증 / 코드 / 시간 / 제출 중 하나로 기록한다.
6. 강의의 완료 기준을 스스로 충족했는지 확인하고 완료 표시를 한다.

권장 공부 시간은 입문 과정 하루 1.5~2.5시간, 본과정 하루 2.5~4시간, 압축 일정 하루 4~6시간이다. 코딩이 처음이라면 진도를 서두르기보다 코드를 실행하고 오류의 원인을 찾는 데 시간을 쓴다.

## 입문 — 파이썬을 처음 배우는 사람을 위한 10일

이 일정의 강의 번호는 웹사이트의 **Python 기초 1~10강**을 가리킨다. 그날의 실습문제와 완료 기준을 확인한 뒤 다음 강의로 넘어간다.

- [ ] **입문 1일차 · 기초 1강** — Jupyter 셀과 커널의 역할을 익히고, 현재 폴더와 오류 메시지의 마지막 줄을 확인한다.
- [ ] **입문 2일차 · 기초 2강** — 변수에 숫자·문자열·불리언 값을 담고, 연산 결과와 `type`을 출력한다.
- [ ] **입문 3일차 · 기초 3강** — 리스트·튜플·딕셔너리·집합을 만든다. 인덱싱과 슬라이싱으로 어떤 값을 가져올지 먼저 예상한다.
- [ ] **입문 4일차 · 기초 4강** — 작은 예제로 조건문·반복문·함수·예외 처리 코드를 직접 작성한다.
- [ ] **입문 5일차 · 기초 5강** — `np.array`로 배열을 만들고 `shape`, `ndim`, `dtype`의 뜻을 설명한다.
- [ ] **입문 6일차 · 기초 6강** — 인덱싱, 축, 배열 모양 변경, 브로드캐스팅, 뷰와 복사의 차이를 출력 결과로 확인한다.
- [ ] **입문 7일차 · 기초 7강** — `pd.DataFrame`, `head`, `info`, 열 선택, `loc`·`iloc`를 연습한다.
- [ ] **입문 8일차 · 기초 8강** — 결측값과 자료형을 정리하고, 조건으로 행을 고르거나 그룹별 집계·표 병합을 수행한다.
- [ ] **입문 9일차 · 기초 9강** — 히스토그램·막대그래프·산점도를 그리고 축과 단위를 읽는다.
- [ ] **입문 10일차 · 기초 10강** — CSV를 점검하고 학습 데이터에서 구한 기준으로 전처리한다. 이어서 NumPy 배열, float32 텐서, DataLoader를 만드는 과정을 끝까지 실행한다.

입문을 마치면 `python-data-basics-starter.ipynb`의 빈칸을 처음부터 다시 채운다. 막힌 셀만 정답 노트북과 대조한 뒤 아래 본과정을 시작한다.

## 본과정 — Python 기초를 마친 뒤 공부하는 21일

### 1단계: 시험 구성과 수학·코딩 기초

- [ ] **1일차 · 1강** — 공식 시험 구성, 공개 범위, 금지행위, 저장·제출 지시를 읽고 준비할 내용을 정리한다.
- [ ] **2일차 · 2강** — Python 객체와 배열의 축·인덱싱·복사·뷰·브로드캐스팅을 작은 예제로 확인한다.
- [ ] **3일차 · 3강** — DataFrame의 크기·자료형·결측값·무한대·중복·정렬 상태를 점검하는 함수를 만든다. 익숙해지면 2분 안에 점검하는 연습을 한다.
- [ ] **4일차 · 4강** — 행렬곱과 선형층의 입력·가중치·출력 배열 크기를 손으로 계산한다.
- [ ] **5일차 · 5강** — 연쇄법칙, 역전파, 기울기 누적, 옵티마이저의 매개변수 갱신을 PyTorch로 확인한다.
- [ ] **6일차 · 6강** — 가능도, 엔트로피, 교차엔트로피, 편향과 분산을 작은 수치 예제로 익힌다.

### 2단계: 데이터 처리·검증·머신러닝

- [ ] **7일차 · 7~8강** — 정답·그룹·시간에 따라 데이터를 탐색한다. 결측값 처리·이상치 처리·스케일링·인코딩의 기준은 학습 데이터에서만 구한다.
- [ ] **8일차 · 9~10강** — 특성 생성·선택·PCA를 익히고, 선형회귀·로지스틱 회귀·KNN을 기준 모델로 비교한다.
- [ ] **9일차 · 11~12강** — 트리·앙상블·SVM, 군집화·DBSCAN·PCA의 가정과 쓰임을 표로 정리한다.
- [ ] **10일차 · 13강** — 무작위·층화·그룹·시간순 분할 중 상황에 맞는 방법을 고르고, 데이터 누수 사례를 세 가지 만든다.
- [ ] **11일차 · 14~15강** — 회귀·분류 지표, 데이터 불균형, 분류 임계값, 규제를 익힌다. 탐색 횟수를 작게 정해 하이퍼파라미터를 조정해 본다.

### 3단계: PyTorch 핵심 모델

- [ ] **12일차 · 16강** — 텐서 준비 → Dataset·DataLoader → nn.Module → 학습 → 추론 → 저장·불러오기를 끝까지 실행한다.
- [ ] **13일차 · 17~18강** — MLP 출력과 정답이 손실함수의 입력 조건에 맞는지 확인한다. 옵티마이저·초기화·배치 정규화·드롭아웃도 비교한다.
- [ ] **14일차 · 19~20강** — 합성곱의 출력 크기와 매개변수 수를 계산하고 CNN·ResNet·전이학습 코드를 실행한다.
- [ ] **15일차 · 21~22강** — 시간 순서를 고려해 데이터를 나누고 입력 구간의 인덱스를 정한다. RNN·LSTM·GRU·CNN1D의 배열 크기를 비교한다.
- [ ] **16일차 · 23~25강** — 어텐션·Transformer·오토인코더·VAE·GAN의 목적, 주요 손실함수, 입력 조건을 비교한다.

### 4~5단계: 실기 풀이와 모의시험

- [ ] **17일차 · 26강** — Process 함수의 요구사항을 읽고 원본 보존 여부와 경계값 처리를 확인하는 테스트를 만든다.
- [ ] **18일차 · 27강** — 표 데이터 Problem을 데이터 탐색 → 분할 → 기준 모델 → MLP → 검증 → 저장 순서로 푼다.
- [ ] **19일차 · 28~30강** — 시계열·이미지·오토인코더 문제를 각각 연습한다. 제출 파일을 다시 읽어 검사하고 Ctrl+S로 저장하는 순서를 익힌다.
- [ ] **20일차 · 31~32강** — 필기 20문항을 50분 안에 풀고 Process 8문항 모의를 답안 없이 수행한다. 틀린 이유를 분류한다.
- [ ] **21일차 · 33~34강** — 170분 통합 모의를 수행한 뒤 최종 암기표와 취약한 강의를 다시 읽는다.

## 마지막 3일 점검

이 일정은 처음 공부하는 사람에게 적합하지 않다. 앞의 범위를 한 번 이상 공부하고 코드를 직접 실행하는 모의시험을 치러 본 뒤에 활용한다.

- [ ] **D-3** — 필기 20문항을 50분 안에 풀고 Process 8문항을 연습한다. 헷갈린 개념을 13·14·17·18·21·26강에서 다시 읽는다.
- [ ] **D-2** — Problem 1문항을 제한 시간 안에 풀고 저장한 파일을 다시 읽어 확인한다. 새 모델은 추가하지 않는다.
- [ ] **D-1** — 공식 공지·실행 환경·금지행위·접속 준비를 다시 확인하고 오답표와 제출 검사 함수를 복습한다.

## 통합 모의 시간 배분

아래 시간표는 **비공식 권장안**이다. Process 난도와 Problem 데이터에 따라 조정하되, Problem의 첫 유효 제출 파일을 만드는 일을 마지막까지 미루지 않는다.

- 0~8분: 전체 문제를 읽고 변수·파일·평가 지표·제출 위치를 기록한다.
- 8~55분: 확실히 풀 수 있는 Process부터 풀고 저장한다.
- 55~65분: Problem 데이터의 입출력 조건을 확인하고 가장 빠른 기준 모델을 만든다.
- 65~125분: Problem의 검증 방법을 확인하고 모델을 한 번 개선해 본다.
- 125~150분: 남은 Process를 풀고 경계값 테스트를 실행한다.
- 150~163분: 최종 학습·예측·저장을 수행한다.
- 163~170분: Ctrl+S로 저장한다. 예측 파일이 있는지 확인하고 다시 읽어 배열 크기·자료형·유한값·행 순서·파일명과 제출 상태를 검사한다.

55분까지 Process를 끝내지 못해도 Problem의 기준 모델을 만드는 단계로 넘어간다. 125분까지 개선 모델의 성능이 기준 모델보다 좋아지지 않으면 기준 모델을 사용한다. 마지막 7분에는 새 코드를 작성하지 않는다.

## 개인 준비 상태 점검표

아래 수치는 연습을 안정적으로 수행하기 위한 개인 기준이다. 공식 합격선이 아니며, 실제 합격선과 채점 기준은 공개되지 않았다.

- [ ] 필기 20문항을 50분 안에 세 번 풀고, 같은 개념을 반복해서 틀리지 않는다.
- [ ] Process 함수에 상수·NaN·비연속 인덱스·빈 배치를 넣어 경계조건을 검사한다.
- [ ] 표 데이터·시계열·이미지 중 두 유형 이상에서 제출 파일 생성까지 마친다.
- [ ] PyTorch의 Dataset·DataLoader, nn.Module, 학습 반복문, 추론, 저장·불러오기를 빈 코드 셀부터 작성한다.
- [ ] 전처리 기준을 학습 데이터에서만 구하는 이유, 그룹·시간순 분할, 겹치는 입력 구간에서 발생하는 누수를 설명한다.
- [ ] 출력·정답·손실함수의 배열 크기와 자료형 조건을 assert로 검사한다.
- [ ] 저장한 예측 파일을 다시 읽어 배열 크기·자료형·NaN·Inf·행 순서를 확인한다.
- [ ] 170분 통합 모의를 최소 두 번 마치고 시간 기록을 남긴다.
- [ ] 시험 직전에 공식 실행 환경·금지행위·저장·제출 안내를 다시 확인한다.
