- 웹은 9개 장으로 나누고 기존 코드 복사·읽기 설정·모바일 목차를 재사용했습니다. 전체 검색, 유형별 풀이 가이드, 치트시트, 자료실, 오프라인 학습 팩에서 접근할 수 있습니다.

- 작은 전체 흐름 9개와 함수별 예제 44개, 합계 53개: CPU 실행 및 예제 내부 assert 통과.

## 사용 시 남는 확인 사항

예제의 숫자와 열 이름은 실제 시험의 정답 설정이 아닙니다. 문제에서 지정한 모델 구조, 분할, 양성의 뜻, 클래스 순서, 시점 대응, 제출 형식, 파일 사용 규정을 별도로 확인하세요. VAE/GAN·여러 입력·가변 길이 마스크에는 전용 학습 루프가 필요합니다.

전체 학습 팩을 풀었다면 `template-guide.html`을 열고 `scripts` 폴더에서 실행 예제를 실행하세요. 실전 연습팩에서는 매뉴얼과 코드가 같은 폴더에 있습니다. 저장 예제는 임시 폴더를 사용하므로 원래 파일을 덮어쓰지 않습니다. 실제 저장 helper를 직접 사용할 때는 같은 이름의 기존 파일이 없는지 확인하세요.
