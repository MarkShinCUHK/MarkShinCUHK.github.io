# 한국어 문장 교정 기록

교정일: 2026-09-08

## 무엇을 고쳤나요?

영어 어순을 따라간 문장, 영어 명사를 나열한 설명, 뜻이 모호한 비유를 한국어 교재의 문장으로 다듬었습니다. 문장을 짧게 줄이는 데 목적을 두지 않고, 무엇을 확인하고 계산해야 하는지 구체적으로 설명했습니다.

- 본과정 34강의 설명·선택지·실습문제·정답과 해설
- 본과정의 그림 학습 자료 34강과 필기 이론 보충 186절
- Python 기초 10강과 보충강의 4강
- 치트시트와 유형별 풀이 가이드 15페이지
- 실전 연습 15문제와 공통 사용 매뉴얼
- 학습계획표, 그림 68개의 설명, 강의 목록·검색·자료실 등의 안내 문구

본과정을 세 구간으로 나누어 검토한 뒤, 이론 보충과 그림 설명에 남은 번역투를 다시 읽었습니다. 같은 개념이라도 문맥에 따라 자연스러운 말을 골랐습니다. 예를 들어 baseline은 모델을 비교할 때는 ‘기준 모델’, 예측값을 비교할 때는 ‘기준 예측’으로 구분했습니다. ‘계약’은 ‘입력·출력 조건’, ‘제출 조건’, ‘문제의 요구사항’처럼 실제 뜻을 풀어 썼습니다. 시계열의 forecast origin은 ‘예측 기준 시점’으로 설명했습니다.

## 그대로 유지한 내용

수식, 예제의 숫자, 문제 조건, 함수·변수 이름, 출처 링크를 유지했습니다. 코드에 필요한 영어는 번역하지 않았습니다. 개념을 공식 문서에서 다시 찾는 데 필요한 영문 명칭도 함께 남겼습니다.

- 기존 원문을 기준으로 코드·예상 출력 블록 526개의 내용이 같은지 비교했습니다.
- 본과정 34강의 기존 목차 주소와 치트시트의 바로가기 주소를 유지했습니다.
- 문제 371개의 ‘풀이에 필요한 이론’ 연결을 유지했습니다.
- 필기 모의 60문항과 기존 정답·해설 구성을 유지했습니다.
- 웹 강의와 내려받기용 문서가 같은 교정 원문에서 만들어지도록 생성 과정을 정리했습니다.

## 확인 방법

사이트 생성과 HTML 검사에는 강의 수·문항 수·목차 링크·한글 제목의 일치 여부·해설 연결·코드 보존 검사를 포함했습니다. 강조 표시가 잘못 처리되어 별표가 본문에 그대로 보이는 곳도 수정했습니다. 검색·진도 저장·코드 복사 관련 회귀 검사를 함께 수행했습니다.

수학·배열 크기 검산 143개, 학습 원리·입출력 조건 검사 15개, Process 참고답안 검사 8개와 그림 강의의 독립 실행 예제 34개를 실행했습니다. 실행 환경은 NumPy 2.0.2, pandas 2.3.3, PyTorch 2.8.0 CPU입니다. 공식 시험 환경에서 실행했다는 의미는 아닙니다.

## 확인 범위의 한계

이번 개정은 학습자료의 한국어 표현을 다듬는 작업입니다. 새 공식 기출문제를 확보했거나 시험 범위·규정을 새로 확정한 작업은 아닙니다. 실제 기기별 화면이나 모든 보조공학 도구에서 검수한 것은 아니며, 자동 검사만으로 모든 문장이 자연스럽다고 판정할 수도 없습니다. 시험 당일의 문제 지시와 공식 안내가 이 자료보다 우선합니다.
