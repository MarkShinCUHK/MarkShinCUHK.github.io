## 실행·구조 검증

`npm test`의 40개 검사가 통과했다. 새 6개 검사는 다음을 확인한다.

1. 34강의 충분한 설명 분량, 소제목, 그림 2개, 확인문제와 접힌 해설.
2. SVG 68개의 접근성 이름·설명, 외부 이미지 의존 없음, 계산 좌표 기준 글자 잘림과 과도한 줄바꿈 없음.
3. broadcasting, 내적, gradient, Bayes, entropy, 배치 크기, convolution, pooling, attention, 출력 크기의 수치 검산.
4. 새 검색 항목의 앵커 연결과 정답 섹션 제외.
5. 오프라인 교재의 34개 장·68개 내장 그림·고유 앵커.
6. 실제 서버 렌더링 결과에서 34강 전부의 새 설명 순서, 기존 코드·출력·앵커 보존, 두 종류의 목차.

새 코드 34개는 각각 깨끗한 Python 프로세스와 임시 작업 폴더에서 독립 실행해 통과했다. 기존 NumPy·Tensor 기초 32개와 본과정 3강 9개 예제도 재실행했으며, 3강의 잘못된 입력을 거부하는 검사 5개도 통과했다.

확인 환경은 Python 3.9, NumPy 2.0.2, pandas 2.3.3, PyTorch 2.8.0 CPU다. 응시 회차의 공식 실행 환경과 같다고 주장하지 않는다. 코드의 shape·dtype·수치·gradient 등 포함된 assert를 확인한 것이며 모델의 실제 데이터 성능 검증과는 다르다.
